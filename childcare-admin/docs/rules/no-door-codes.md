# No door codes in this folder

**Starter / guess until they teach.**

Never write a keypad code, parent PIN, or fob secret into docs/, work CSVs, or chat. If an export includes that column, drop it before the file stays here. Tell families a code changed only if they asked — never print the new number in a pack. Sign-in PINs are the same rule. Pickup authorization is a name list, not a code list. Passwords to Brightwheel or Procare stay out as well.

# Never release a child

**Starter / guess until they teach.**

You never hand a child to an adult, never wave someone through the door, and never tell a waiting person they may take a child. Pickup work is a list check and a mismatch flag for the director or the closer they name. Typical US centers treat release as a trained staff act with ID in hand. A complete pickup CSV is not permission for you to release. Sign-out gaps stay gaps. This rule does not yield to hurry at closing.

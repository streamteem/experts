# Center calendar file

**Pointer only. No passwords. Starter / guess until they teach.**

The year’s closure list, camp weeks, and tuition-charged holidays as they saved it — workbook, handbook exhibit, or PDF. You copy dates; you do not invent federal-holiday rules. School-district calendars are a second file if they use one for school-age. This tool feeds holiday-calendar packs and extra-care questions on closed days. Confirm the year on the file. They send parent notices unless they taught a send step. Staff-only days stay labeled staff-only.

# Door codes stay out of docs

**Starter / guess until they teach.**

Lobby keypads, fobs, and parent PINs are access secrets. Typical US centers change codes on a schedule or when a family leaves. This Expert never copies a door code, keypad sequence, or raw PIN into docs/, work CSVs, or a write-up. If an export includes a PIN column, drop it or replace it with “on file” before anything lands in this folder. You do not program a fob. Lost-fob lists use a family label, not the credential number if they asked for least detail. Sign-in PINs are the same secret. Pickup authorization is names, not codes. If they asked you to remind families that a code changed, say only that it changed — not the new number. Starter until they teach who at *this* center issues fobs and where the live code list is locked. Vendor locksmith invoices that print a default code get the code redacted before the PDF stays here.

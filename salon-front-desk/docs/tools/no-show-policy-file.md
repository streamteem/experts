# Cancel / no-show policy file

**Pointer only. No passwords. Starter / guess until they teach.**

The posted policy they actually use: cancel window, fee, deposit rules, and how late becomes a no-show. Quote it. Do not replace it with a generic twenty-four-hour rule. Typical files are a lobby card, a saved booking-policy page, or a markdown they keep. You list names from the book; they decide fees. You do not text guests. If the file is missing, ask.

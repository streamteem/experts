# Voids, comps, and discounts

**Starter / guess until they teach.**

Voids, comps, and employee discounts should appear on a POS exception report if they use one. List them. Do not hide a void inside “net sales” without naming it. If a manager override is required in their software, you do not invent the override. Desks keep exception lists so a deleted ticket is visible and so a complimentary blowout is a named reason, not a missing dollar. Typical columns are ticket ID, reason code they use, amount, and who voided if the export has it. You do not void in the live POS. A guest complaint is not a reason for you to add a comp line in the pack. If they have no exception report, list what the ticket export shows and say the exception report was not in the folder. Starter until they teach this shop’s void reasons.

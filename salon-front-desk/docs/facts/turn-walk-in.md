# Turns and walk-ins

**Starter / guess until they teach.**

Walk-ins and “takes the next turn” exist only if their book has a walk-in, turn, or waitlist slot type. Many US nail and blowout bars run a turn list; many color salons do not take walk-ins into a processing block. Desks keep the slot type so a walk-in does not silently steal a reserved chair. Do not drop a walk-in onto a named stylist’s last color processing block unless their file shows that as allowed. If the waitlist is a separate export, keep it separate from confirmed appointments. Typical fields are arrival time, requested service, preferred stylist if any, and a turn number. A phone request that “can come now” is still a request until their process books it. Do not invent a turn order to be fair; use the order on their list. Starter until they teach how this floor takes walk-ins, if it does at all.

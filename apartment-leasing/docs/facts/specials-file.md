# Specials file

**Starter / guess until they teach.**

The specials file is their dated list of live concessions: which floorplans, which lease terms, start and end dates, and the exact offer wording. Typical US desks keep a one-pager for the site team and a matching PMS concession code. You attach specials only as written. You do not invent an internet special to match a competitor ad, and you do not extend an expired row. If the website screenshot they saved disagrees with the internal sheet, quote both and ask which is live. Employee or locator-only specials stay labeled if the file splits them. Stacking with employee discounts or military notes needs their written rule. Specials are not rent-control. This Expert matches the sheet to availability and to lease drafts. They change promotions. Starter until they teach who at *this* shop may edit the specials file and when a new week starts.

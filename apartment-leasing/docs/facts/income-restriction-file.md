# Income-restriction file

**Starter / guess until they teach.**

An income-restriction file is their affordable or workforce program sheet: AMI limits, student rules as they printed them, and which units are restricted. Typical US mixed communities keep a compliance binder or software export. You quote limits and unit flags only from that dated file. You do not invent an AMI percentage, and you do not decide a household is over or under income. Completeness of their program application is still present-or-missing, not a compliance stamp. Market waitlists and affordable waitlists stay separate. Recertification calendars, if they have them, are list work — not a tax or HUD legal opinion. If the file is missing, ask; do not use last year's flyer from another property. This Expert lists restricted units and missing program forms. Their compliance person qualifies households. Starter until they teach which program *this* shop runs and which file is official.

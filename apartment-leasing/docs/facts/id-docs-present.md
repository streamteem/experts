# ID documents present

**Starter / guess until they teach.**

ID-documents-present means their checklist asked for a government photo ID and a readable copy is in the application folder, or it is missing. Typical US leasing offices accept a driver's license, state ID, or passport image uploaded to the PMS or scanned to a PDF folder. You mark present, missing, expired-as-they-dated, or unreadable. You do not decide that an ID type is legally valid, and you do not opine on citizenship or immigration. Minimum necessary: list that a photo ID is on file, not the ID number, not the SSN, and not a extra photocopy in docs. If two applicants apply together, each needs their own ID row if their checklist says so. A student ID or gym card is not a government photo ID unless their file says they accept it. Do not crop or enhance an image to make it pass. This Expert only reports presence. They collect a better scan. Starter until they teach which ID types *this* shop's checklist names.

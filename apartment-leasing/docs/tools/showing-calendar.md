# Showing calendar

**Pointer only. No passwords. Starter / guess until they teach.**

The showing calendar is their Outlook, Google, or PMS tour book: date, time, prospect, unit or floorplan, and show versus no-show. You build the day list from it. You do not add a fake appointment. Hours still gate the list. Virtual and self-guided rows stay labeled if they coded them. No calendar password is stored here. Checks look for date, unit, and prospect on the work file. This tool feeds showing-day and hours-and-tours packs.

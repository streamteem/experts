# Application PDF folder

**Pointer only. No passwords. Starter / guess until they teach.**

The application folder holds PDFs and uploads they dropped: application, ID image, income papers, and extra forms. You mark present or missing against their checklist. You do not decide income or credit. You do not retype SSNs into docs. Unreadable scans are missing-quality. Guarantor and roommate packets sit in the same folder if they filed them that way. No applicant-portal password belongs here. Checks confirm the index or folder file exists. This tool starts the application-completeness workflow.

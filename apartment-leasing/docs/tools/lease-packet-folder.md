# Lease-packet folder

**Pointer only. No passwords. Starter / guess until they teach.**

The lease-packet folder holds the draft or signed lease plus addenda they generated: pet, parking, policies, lead pages, insurance proof. You checklist completeness. You do not rewrite clauses or decide enforceability. Version dates matter when two packets sit side by side. Unsigned drafts stay labeled draft. Concession riders must match their specials file if both are present. No e-sign admin password belongs here. Checks look for the index file the step names. This tool starts the lease-packet pack.

# Availability sheet

**Pointer only. No passwords. Starter / guess until they teach.**

The availability sheet is their unit-by-unit export: unit, floorplan, status, date available, and posted rent if they include it. You treat it as live inventory. You do not flip a status. Holds and models stay as coded. If the sheet is stale, ask for a new export. No PMS password is stored here. Checks expect unit and status columns when the workflow says so. This tool feeds showing-day, specials, and mix write-ups.

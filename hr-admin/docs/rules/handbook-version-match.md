# Handbook version must match

**Starter / guess until they teach.**

Acknowledgments must carry the version string printed on the signed page. Compare that string to the live handbook PDF they stored. If they disagree, list both and ask — do not silently treat last year’s book as current. Do not rewrite chapters. Do not interpret a clause as employment law. Draft handbooks stay draft. Missing ack is missing, not a guessed date. They publish and they collect signatures. Extra policy acks still need their own version strings when they use stand-alone pages.

# Never store SSNs in docs/

**Starter / guess until they teach.**

Never type a Social Security number into docs/, work CSVs, or the write-up. Typical US SMB packets contain W-4s and I-9s with SSNs; those stay in their payroll or I-9 folder, not this working tree. Use name and employee number they already assigned. If a source file shows an SSN, do not copy it. Same rule for full bank account numbers. FTC small-business guidance is orientation for minimum necessary. Ask them to keep sensitive forms out of the shared drop.

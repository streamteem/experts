# Do not invent a start date

**Starter / guess until they teach.**

Start date comes from their offer letter or hire sheet. Do not invent a Monday to make I-9 dates look tidy. Do not use a remembered two-week notice. If offer start and payroll hire date disagree, list both and ask. Orientation day is not automatically start date. A delayed start needs their updated note. Rehire dates come from the new file, not the old tour, unless they wrote a bridging rule.

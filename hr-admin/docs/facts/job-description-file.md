# Job description file

**Starter / guess until they teach.**

A job description is their dated file of duties, requirements they wrote, and the job title that matches the offer if they keep them aligned. Typical US SMB shops have short one-pagers or none at all. You attach or list the file that matches the title they named. You do not write a new description from a public job-board memory. You do not decide essential functions as ADA counsel. If the description date is older than a reorg note, list both and ask. Physical-requirement lines stay as they wrote them; you do not add lifting weights. This file is not an exempt-status legal opinion even if it mentions supervision. This Expert matches title to the description file they stored. They own the duties. Starter until they teach whether *this* shop keeps descriptions and where the current set lives. Posted ads are not job descriptions unless they said the ad file is the description.

# Org chart file

**Pointer only. No passwords. Starter / guess until they teach.**

The org chart file is their slide, PDF, or sheet of reporting lines and departments. You use it for supervisor, department, and offboard routing when they said the chart wins. You do not add boxes. Vacant seats stay vacant. If two charts exist, ask which is current. Date the pack with the file date if shown. This tool supports offboard checklists and roster packs. They update the picture. No passwords.

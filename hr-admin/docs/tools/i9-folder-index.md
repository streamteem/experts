# I-9 folder index

**Pointer only. No passwords. Starter / guess until they teach.**

The I-9 folder index is a sheet they maintain: employee name, start date, Section 1 date, Section 2 date, and reverify date if they track one. Typical US SMB offices keep the actual forms elsewhere. You copy dates as written. You do not invent dates. You do not store SSN or ID images in this folder. Checks may ask for name and a section-date column. This tool feeds I-9 section-date packs and reverify-due lists. They complete the forms with the employee.

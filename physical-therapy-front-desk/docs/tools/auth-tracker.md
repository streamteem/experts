# Authorization tracker

**Pointer only. No passwords. Starter / guess until they teach.**

Their workbook or EHR auth log: chart label, payer, auth number as printed, authorized visits or units, used as they posted, remaining as they posted, dates. Copy columns as they named them. Do not invent remaining. Do not apply KX. If tracker and a letter disagree, quote both. No tracker password belongs here. This tool feeds auth-remaining and visit-count checks. Starter / guess until they teach which columns *this* clinic treats as live. Attachments are present or missing by filename; you do not invent an auth number so the row looks complete.

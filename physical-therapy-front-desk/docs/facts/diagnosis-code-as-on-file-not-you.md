# Diagnosis code as on file, not you

**Starter / guess until they teach.**

Diagnosis or ICD labels on a typical US PT referral, POC, or claim export stay as already printed. You may list the code as a label on a paperwork index if they asked. You do not choose a diagnosis. You do not add a code to make an auth fit. You do not treat. You do not diagnose from a body-region word. If the referral code and the claim export disagree, quote both and ask. Missing code: ask; do not invent M25.511 because the slot says shoulder. CMS ICD-10 pages are orientation, not a codebook you apply as care. Do not copy extra assessment text into docs/. Starter / guess until they teach which file *this* clinic treats as the live diagnosis label. A body-region word on the book is not an ICD you may type to complete a blank claim field.

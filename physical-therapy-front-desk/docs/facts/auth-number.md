# Authorization number

**Starter / guess until they teach.**

An authorization number is copied only from their payer letter, portal print, or form image. Typical US PT claim rows need that number when the plan issued one. If it is missing, ask. Do not invent a number so the claim or day list looks complete. Do not reuse last year’s number. Do not promise the plan approved payment because a number exists — quote the letter’s status words. Do not add CPT to the letter. Dates that miss the booked visit are a flag, not a number you stretch. Prefer chart label plus the number as printed, without extra member IDs. Starter / guess until they teach which field *this* clinic treats as the live auth number. A number on a sticky note they did not save as a letter image is a question, not an auth you copy.

# HEP PDF as their library

**Starter / guess until they teach.**

A home-exercise program at this desk is a PDF or print packet already in their library or already attached to the chart by the therapist: named program, version or date if they store one, and body-region label as they filed it. Typical US PT clinics use MedBridge, Physiotec, HEP2go, or a clinic-built PDF folder. You index the file they named. You do not write a new exercise program. You do not add reps, sets, or progressions. You do not treat. You do not diagnose which HEP the patient needs. If the therapist has not attached a HEP and they asked for a print, say the named file is missing — do not pick a shoulder packet from the library as care. Do not copy exercise instructions into docs/ when a filename will do. Starter / guess until they teach how *this* clinic names and versions HEP PDFs. A library folder named by body region is not permission to assign that packet as care.

# Weigh-ticket folder

**Pointer only. No passwords. Starter / guess until they teach.**

Scanned scale tickets and photos they saved sit here: tare, gross, net, scale name, unit, date. You copy printed numbers. You never invent a pound. Missing empty or loaded slip: say which. Fleet empty weight is not this folder unless they filed a slip. No scale-club login belongs here. This tool is the source for weigh-ticket packs and any estimate that already has a ticket. They scale. You pack slips and questions.

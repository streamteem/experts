# Conflict check

## When

**teach** / **remember** / **after-task** would write something that contradicts an existing fact or rule.

## Do

1. Quote the old entry (path + date) and the new statement.
2. Ask which is true now.
3. Winner → update or replace the file. Loser → strike through or move to `docs/archive/` with a one-line why.
4. INDEX stays accurate.

Do not keep two opposing rules live. Do not pick silently.

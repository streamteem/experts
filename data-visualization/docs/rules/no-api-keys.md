# No API keys in scripts or charts

**Starter / guess until they teach.**

Never store API keys, tokens, or service passwords in the workspace, in a notebook, or on a chart. This desk does not call live APIs as the product. If a library wants a key to download tiles or series, skip that path and ask for a saved file. Keys are secrets like bank logins. Missing package is an install ask, not a key ask. Tokens in environment files in this folder are also out.

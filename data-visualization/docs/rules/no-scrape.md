# Do not scrape live sites

**Starter / guess until they teach.**

Never scrape a website, pull a live API, or re-export from a portal as this product. Charts come from files they dropped. If a file is missing, ask them to save it. No API keys in the folder. No “I will just fetch the rest.” A public CSV they already saved is a file, not a scrape. This desk is not a collector and not a BI live query. Missing export: ask them to drop it again.

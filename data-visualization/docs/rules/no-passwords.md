# No passwords in this folder

**Starter / guess until they teach.**

Never store passwords, bank logins, or card numbers in this folder. Never put a portal password in a script to refresh a chart. If a notebook or requirements note needs a secret, refuse and ask them to drop an export instead. This is the shared money-and- secrets rule applied to a Python desk. Charts come from files already saved. A notebook cell with a pasted password is the same failure.

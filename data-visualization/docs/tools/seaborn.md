# seaborn for readable statistical pictures

**Pointer only. No passwords. Starter / guess until they teach.**

This desk uses seaborn, when installed, for histograms, bars, boxes, and small multiples they asked for. Typical calls: import seaborn, set a colorblind theme, histplot or barplot or relplot with the facet they named, then save the figure to out/. Done is the PNG plus the pandas table behind it. If seaborn is missing, ask and install, or use matplotlib only — do not fake a seaborn file. Themes are readability, not a brand product. No red-green-only encoding.

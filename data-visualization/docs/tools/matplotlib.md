# matplotlib for chart files

**Pointer only. No passwords. Starter / guess until they teach.**

This desk uses matplotlib to draw the chart they asked for and save it. Typical calls: import matplotlib.pyplot, create a figure, plot hist or bar or plot or scatter, set title and axis labels with units, then savefig to out/*.png or .pdf. Done is that named file, not a popup. If matplotlib is missing, ask and install; do not drop an empty picture. Defaults are a start; make ticks readable. No causal titles. Colorblind defaults apply. Tight layout so titles are not clipped.

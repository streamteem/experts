# pandas for tables

**Pointer only. No passwords. Starter / guess until they teach.**

This desk uses pandas to load their CSV or Excel, filter columns they named, groupby the grain they asked for, and write work CSVs. Typical calls in ordinary English: read the file, parse the date column, group and sum or count, then to_csv. Done is a tidy work table whose columns match the chart. If pandas is missing, ask and install; do not type totals into a fake PNG. Do not invent columns. Do not scrape. read_excel is for workbooks they dropped. This is not a warehouse model.

# scipy.stats for optional description

**Pointer only. No passwords. Starter / guess until they teach.**

This desk uses scipy.stats, when installed, only for a descriptive number they asked for — a correlation, a percentile, or a summary. Typical calls: import scipy.stats, pearsonr or spearmanr or describe on the two columns they named, write the number to work/*.csv. Done is that file plus wording that a p-value is not a decision. If scipy is missing, ask and install, or stay with pandas; do not fake a test output. No test-hunting. Not a data-scientist engagement.

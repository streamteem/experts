# Annotations from a file they stored

**Starter / guess until they teach.**

An annotation is a date or category mark that comes from a file they stored: a holiday list, a store-open date, a note column. Typical US SMB owners remember “that was the flood week” but the desk only plots it when the date is in a file. The Expert may run Python, merge the annotation file on the key they named, and call annotate or axvline, then save the PNG. Do not invent an event. Do not scrape a holiday API. Do not write a witty callout that claims a cause. If the annotation file is missing, the chart stays unannotated and the write-up says so. PII does not appear in callouts. Text stays short so it does not cover the series. A work CSV can list which annotation dates fell inside the plotted range. This is still a descriptive chart, not a news product. Starter until they teach where *this* shop keeps event dates.

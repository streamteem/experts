# Chart file formats

**Starter / guess until they teach.**

Chart deliverables on this desk are files: PNG for slides and chat, PDF for print, SVG if they asked and the library can write it. Typical US SMB owners want a PNG they can paste. The Expert calls savefig or FacetGrid.savefig to a path under out/ with a name that includes the question slug and a date if this is a refresh. Do not deliver only a GUI window. Do not screenshot a notebook and call it the chart file if they asked for a named PNG. DPI is an ask; a readable default is fine and should be written if they care about print. PDF pages that hide a second series are not a trick you use. Keep the work CSV of plotted values next to the picture. If matplotlib is missing, ask and install; do not drop a blank PNG. This is not a hosted dashboard. Starter until they teach which format *this* shop pastes into the weekly note.

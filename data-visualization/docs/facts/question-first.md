# Question first, then a chart

**Starter / guess until they teach.**

The question comes first: what they want to see, which columns, which date range, which filters. Typical US SMB requests arrive as “make it pretty” or “dashboard everything.” This desk will not invent a question to justify a gallery. The Expert writes their question in the title and the write-up, then picks histogram, bars, line, or scatter that fits that question. Do not start from a chart type and hunt a column. Do not add extra plots as a data-science sampler. If the question is causal (“why did sales rise”), restate what you can plot (what changed in the file) and refuse the causal stamp. If the question is a forecast, refuse that as a product. Done is a named file that answers the named question, plus what was not claimed. Starter until they teach the weekly question *this* shop actually asks.

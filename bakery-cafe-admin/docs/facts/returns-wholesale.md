# Wholesale returns

**Starter / guess until they teach.**

Wholesale returns are crates or unsold units an account sent back, logged on their return file — not a restaurant vendor credit you invent and not a stale from the cafe case. Typical US SMB shops that allow returns write account, item, qty, date, and reason. You copy that file. You do not invent a return to close a standing variance. You do not invent a credit dollar. Credit drafts need their price file or invoice line; still they send the credit. Some shops forbid returns; if no file exists, say so. Stales in-house stay on the stale log. Starter until they teach whether *this* shop takes wholesale returns. An account that sent back muffins is not a cafe stale. You do not invent a credit dollar from the return qty. Starter until they teach whether *this* shop allows wholesale returns and which reason codes they use.

# Ask if the formula is missing

**Starter / guess until they teach.**

If the bake list, cake ticket, or holiday tab names an item and the formula file has no card, stop and ask. Do not invent a formula so the mix can start. Do not fill weights from a baking book. Do not reuse last year's seasonal card unless they said it is live. Flavor-from-menu still needs a file. They supply the formula. Holiday specials and off-menu cake flavors still need a card. Last year's seasonal file is live only if they said so. They supply the formula.

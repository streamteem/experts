# Formulas come from their file

**Starter / guess until they teach.**

Every dough, batter, buttercream, filling, and starter weight comes from a formula file they stored. Never invent a formula, a baker's percent, or a missing ingredient line. If the bake list names an item with no file, stop and ask. Verbal recipes are missing files. Secret family formulas do not go into a wide pack unless they asked. This desk is bake-plan and case, not a recipe author and not a restaurant line cook inventing a sauce.

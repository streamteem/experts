# Standing changes from their file

**Starter / guess until they teach.**

Apply pauses, cuts, and adds only from a standing-change note with an effective date. Do not invent a pause because a holiday is near. Do not keep last week's extra as the new standing. Two notes that disagree stay listed. After the effective date, the wholesale-day pack uses the new qty. They tell the account. A remembered extra is not a change. Pause and close are different codes if they use them. They tell the account.

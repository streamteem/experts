# COI folder

**Pointer only. No passwords. Starter / guess until they teach.**

Certificate-of-insurance PDFs the renter or vendor dropped live here. You list present versus missing and printed date ranges. You do not decide coverage. You do not invent required limits. Expired files on still-scheduled events stay flagged. No insurer-portal password belongs here. This tool supports facility-coi-missing. Member-only exemptions come from their policy file, not from an empty folder. They chase groups. You index. Waive only if they stored a written waive.

# Statement process file

**Pointer only. No passwords. Starter / guess until they teach.**

The statement process file is their SOP or software checklist for contribution statements: who is included, which funds print, and who sends. You follow only that file. You do not invent deductible wording. Missing file: ask before a run list. This tool starts the statement-run-list workflow. IRS pages are orientation, not a substitute. They send statements. You list households and holes the process names. Checks look for the process file when the workflow asks.

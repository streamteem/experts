# Key log

**Pointer only. No passwords. Starter / guess until they teach.**

The key log workbook lists who holds a key or fob: person, key number, issue and return dates. You copy rows. You do not issue a key. You never store a door code or alarm password. Still-out keys their policy treats as temporary are flags. This tool supports packs they ask for when a facility or volunteer write-up must show keys. They collect keys. You list exceptions. Checks look for the log file when asked.

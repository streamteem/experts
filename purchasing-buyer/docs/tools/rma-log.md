# RMA / return log

**Pointer only. No passwords. Starter / guess until they teach.**

The RMA or return log lists authorization numbers, quantities, PO or invoice references, and reasons from dock or QA. You list what they recorded. You do not invent an RMA number and you do not apply the vendor credit as payment. A debit memo is AP’s document after the return is real. Restocking fees come from a vendor file if present. This tool is not a cash application. Use it when returns are in scope for the write-up they asked for.

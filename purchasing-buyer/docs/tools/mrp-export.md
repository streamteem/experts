# MRP or suggested-order export

**Pointer only. No passwords. Starter / guess until they teach.**

The MRP or suggested-order export is a planning suggestion only: item, suggested qty, and a date. It is not an issued PO. It still needs AVL, MOQ, price file, and approval. Do not copy a planned row onto letterhead as live. Do not invent a firm date the export left blank. No ERP login is stored here. Use this file when they asked you to start from planning, then apply the same buyer checks as any other need. They firm the order.

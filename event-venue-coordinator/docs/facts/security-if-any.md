# Security (if any)

**Starter / guess until they teach.**

Security officer counts, start times, and vendor name come from their security policy file or the BEO — never from a guessed “one guard per hundred.” Typical US venues require officers for cash bars, teen events, or outdoor concerts per a written matrix. You copy the matrix result only when the inputs they use are on file (event type, count, end time). You do not invent a headcount of officers. You do not hire off-duty police as this product. You do not serve as security. If the matrix is missing, ask. Client-hired security still needs their COI if that is their rule. You list required versus booked from their sheets. They book the firm. Starter until they teach *this* venue’s security matrix. Cash-bar nights and eighteen-and-up events often sit on different rows of their matrix; use the matching row only. You do not write a use-of-force rule. Missing booked-versus-required is a flag they close with the security vendor.

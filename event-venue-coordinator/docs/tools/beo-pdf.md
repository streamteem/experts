# BEO PDFs

**Pointer only. No passwords. Starter / guess until they teach.**

Banquet event order PDFs they drafted or issued are the source for function name, room, times, setup, menu lines, counts, and extras. Typical US desks export from a catering system or save Word-to-PDF forms. You copy lines as written. You do not invent a price or a guarantee. Draft versus issued stays labeled. Revision date on the PDF matters. No catering-system password belongs in the folder. This tool feeds BEO packs, load-in calendars, guarantee-versus-setup, and banquet-check comparisons. If the folder is empty, name the missing functions from the definite sheet and ask.

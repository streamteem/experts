# Group resume PDF

**Pointer only. No passwords. Starter / guess until they teach.**

Resume or specification-guide PDFs cover multi-day groups: billing notes, VIP flags, and a function list. You do not invent amenities. The resume should point to BEOs, not replace missing ones. Billing instructions are not a card you run. No hotel-system password is stored. Use this file when they asked for a group pack or when hold-versus-definite needs the in-house group context. One-room social events may have no resume; say none rather than inventing a cover.

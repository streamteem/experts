# Diagram PDFs

**Pointer only. No passwords. Starter / guess until they teach.**

Dated room-diagram PDFs are layout truth for tables, stage, dance floor, and bars. You attach the latest revision and log older dates when asked. You do not redraw exits or stamp fire approval. Chair counts on the diagram are compared to the BEO, not silently fixed. Undated pretty pictures are questions. This tool feeds guarantee-versus-setup and diagram-revision-log packs. No layout-software login belongs here. If a definite function has no diagram and their process requires one, say missing.

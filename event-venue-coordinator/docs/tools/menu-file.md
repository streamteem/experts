# Menu and package file

**Pointer only. No passwords. Starter / guess until they teach.**

The dated banquet menu, wedding package, or contract exhibit is the price and inclusion source for BEO lines. You copy dish names and printed prices. You do not invent a plate price, corkage, or cake-cutting fee. Expired seasonal menus become asks. Dietary notes are labels, not diagnoses. This tool supports BEO packs and any spend-versus-minimum math that uses only their printed prices. No POS password belongs here. If the planner’s email names a dish that is not on the file, ask.

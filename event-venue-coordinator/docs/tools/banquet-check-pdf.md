# Banquet check PDFs

**Pointer only. No passwords. Starter / guess until they teach.**

Posted banquet-check PDFs are the bill to compare to the BEO: food, beverage, labor, service charge, tax from their tax file, and incidentals. You list mismatches. You do not invent tax. You do not mark paid or store PAN. Signature present or missing is a file fact. This tool is the source for the banquet-check-file workflow. Missing check after a definite function is a row on the exception list. Captains’ extra slips belong with the check if they scanned them.

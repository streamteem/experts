# No passwords or portal logins

**Starter / guess until they teach.**

Never store passwords, PMS logins, AV-portal logins, or insurance-portal credentials in this folder. Export or PDF drops only. Door codes, elevator keys, and alarm codes stay out of docs. If they pasted a password into a note, do not copy it into the pack — ask them to remove it. This rule is shared across desks and is not optional on a busy wedding weekend. PMS, AV portals, and shared-drive logins never belong in docs. If a planner pasted a code into a timeline, omit it from the pack and ask them to remove it from the folder. Alarm and elevator codes are the same rule.

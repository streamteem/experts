# No alarm or lock codes

**Starter / guess until they teach.**

Never store alarm codes, gate PINs, lockbox codes, or badge secrets in docs/. Access is a process description. After-hours vendor lists use names they already published, not panel codes. If a ticket PDF contains a code, do not copy it into the write-up. They keep codes elsewhere. You list the process, not the secret. Contractor gate instructions that include a code get reduced to see their vault, not pasted. Badge PINs are secrets. After-hours vendor pages stay names and published numbers only.

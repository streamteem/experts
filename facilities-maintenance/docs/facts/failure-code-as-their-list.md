# Failure code as their list

**Starter / guess until they teach.**

A failure code is a problem, cause, or remedy code from the list they stored on the work order or in a CMMS picklist. Typical US plants use a short in-house list or a trimmed ISO-style list they already adopted. Use only codes on their list. Do not invent a cause from a photo or from the requester's sentence. Do not diagnose as the technician. The completion note they typed is not a code unless they coded it. If problem and cause are blank at close, say blank — do not fill a neat triad to make the report look complete. Downtime codes and failure codes may differ; keep them separate unless they mapped them. This is not an OSHA accident code. They code the ticket. You list their codes. Starter until they teach which fields *this* plant requires at close and who may edit a code after the fact.

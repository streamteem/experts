# Downtime code

**Starter / guess until they teach.**

A downtime code is the reason label they already use on the downtime log: electrical, mechanical, waiting parts, changeover, no operator, utilities. Typical US plants keep a short list in the CMMS. Copy the code from the row. Do not invent a code because the work-order description sounds like bearings. Do not translate their code into an ISO failure code unless they already map it. If the log is blank and the work order has a failure code, do not copy across unless they said those lists are the same. Hiding an uncoded outage is not allowed. Codes are not OSHA citations. Planned versus unplanned is their flag, not a guess from the clock. They pick the code. You list it. Starter until they teach the code list *this* plant uses and who may change a code after the shift ends.

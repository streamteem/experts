# Install date

**Starter / guess until they teach.**

Install date is the in-service or start-up date they stored on the asset: when the unit became theirs to maintain. Typical US plants use it to start a warranty clock or to age a replacement ask. Copy the date from the asset file. Do not invent an install date from a remembered project year. Do not use a drawing date as install unless they said so. If warranty start and install disagree, quote both. Construction substantial-completion dates are a different desk unless they stored that date as install. A relocated asset may keep the original install or get a new one; use their rule. Missing install on a new asset is an ask. They own the date. Starter until they teach how *this* plant sets in-service and what happens when a unit is moved. Rebuild or overhaul dates are separate if they stored them. Do not replace install with the last overhaul to make warranty look open.

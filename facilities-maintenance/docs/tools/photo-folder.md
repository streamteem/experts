# Photo folder

**Pointer only. No passwords. Starter / guess until they teach.**

The photo folder holds named images tied to a work order: before, after, nameplate. You list file names. You do not invent what an unopened photo shows. You do not diagnose from a picture. Extra faces stay off the write-up unless their process uses them. This tool supports dispatch or closeout packs when they asked for photos. Missing required images stay missing. No camera-cloud password belongs here. EXIF dates are used only if they asked and the file opens. You do not rename files to invent a standard. Broken CMMS links are missing. This folder is not a field-trade closeout product.

# Asset list

**Pointer only. No passwords. Starter / guess until they teach.**

The asset list is their register: asset, description, location, serial, install-date, warranty-end, criticality as stored. You do not invent a tag or a warranty year. Hierarchy parents stay as they built them. No CMMS password belongs here. This tool supports pm-due and asset-warranty-due. Checks look for asset and warranty-end or next-due joins when the workflow asks. Missing serials stay blank. Parent and child rows stay distinct. You do not invent install dates to complete a warranty join. Status retired stays retired. Duplicate tags are a question, not a silent merge.

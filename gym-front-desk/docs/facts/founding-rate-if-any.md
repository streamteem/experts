# Founding rate if any

**Starter / guess until they teach.**

A founding or charter rate, if they used one at opening, is a locked dues amount on a cohort file or a plan name: who qualifies, whether the lock survives a freeze or a cancel-and-rejoin, and the dollar on that file. Typical US SMB clubs honor it only for members on the original list. You copy the lock as written. You do not invent a founding price for a new join. You do not move a later member onto the founding plan to be nice. If the lock file and the live dues export disagree, quote both. A “founding” sticker with no file is a question. This Expert lists who is tagged founding and the file rate. They decide exceptions. Starter until they teach whether *this* club still has a founding cohort. Do not present a starter lock as this shop’s live promise.

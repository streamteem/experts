# No class overbook unless their file says so

**Starter / guess until they teach.**

Booked count may not exceed the capacity on their schedule file unless that file has an overbook or overflow rule. Do not add a spot to be helpful. Do not invent capacity. A waitlist row is not a booked seat. Holiday hours still beat a leftover series. They add a bike or a mat. Starter until they teach this studio’s capacity and overbook rule. If capacity is blank on the schedule, stop and ask before listing a full class.

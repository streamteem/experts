# Workers'-comp code as their file

**Starter / guess until they teach.**

A workers'-comp class or WC code is the code on their policy excerpt, client setup, or assignment — a label they already chose. Typical US SMB staffing offices store a class per client or per job type. You copy the code as written. You do not invent a class to lower a quote. You do not give a compensability or classification opinion. If two codes appear for one assignment, quote both and ask. Injury routing still uses the incident file, not this code as a verdict. This Expert lists the code on rate and assignment packs. They and the carrier own class. Starter until they teach where *this* shop stores WC class versus the bill rate. A change of class mid-assignment needs their change note. You do not pick a cheaper code after an injury. Certificate-of-insurance requests are a file-present flag, not a coverage opinion.

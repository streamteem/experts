# Class code (staffing / pay class)

**Starter / guess until they teach.**

Class code here is their staffing classification on the order and assignment: laborer, machine operator, clerk as they named it — sometimes the same string as a WC class, sometimes not. Typical US SMB staffing desks use class to pick the rate card row. You copy the class as written. You do not invent a nicer class to raise pay. You do not reclassify duties as counsel. If the order class and the assignment class disagree, list both and ask. Skills tags are not automatically a class. This Expert joins rates on their class. They set the class with the client. Starter until they teach the class list *this* shop uses and whether WC class is a separate column. Bill class and pay class can differ if they split them; keep both. A promotion mid-assignment needs their change form. You do not reclass from a job-description verb. Light duty they coded stays their class if they wrote one.

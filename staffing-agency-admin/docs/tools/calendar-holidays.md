# Holiday calendar file

**Pointer only. No passwords. Starter / guess until they teach.**

The holiday calendar is their dated agency list and any client plant calendars they stored. You pack holiday weeks from this file plus assignments and the rate file for premiums. You do not invent federal holidays. If two calendars disagree, the pack quotes both. Checks may be file-exists or a date column they use. This tool starts holiday-shift-list. Shutdown weeks stay as the client wrote them. Premium dollars still come from the rate file, not from this calendar alone.

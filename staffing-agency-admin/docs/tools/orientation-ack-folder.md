# Orientation acknowledgment folder

**Pointer only. No passwords. Starter / guess until they teach.**

The orientation-ack folder holds sign-ins, safety-video acks, handbook acks if they keep them here, and drug-policy acks they already collect. You mark present or missing by person and by packet name they use. You do not invent an agenda. You do not treat a missing tick as a citation. Checks may look for name and date on an index you write. This tool feeds orientation-missing packs. Agency versus client-site packets stay separate rows if they split them. No LMS password belongs here.

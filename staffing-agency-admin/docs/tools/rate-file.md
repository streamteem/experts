# Rate file

**Pointer only. No passwords. Starter / guess until they teach.**

The rate file is their dated card or agreement extract: class or client, bill, pay, OT rates if they print them, diffs, holiday premiums, conversion fee if stored here, and markup only if they wrote it. Missing or expired card: ask. You do not invent a markup. Checks may look for client or class plus a rate column. This tool feeds holiday-shift and assignment packs that must quote money. They version the card. No AP-portal password belongs here.

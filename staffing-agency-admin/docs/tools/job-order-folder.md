# Job-order folder

**Pointer only. No passwords. Starter / guess until they teach.**

The job-order folder is their PDFs and sheet of client requests: order number, client, shift, headcount, status, and pointers to description or rate. Typical US SMB offices drop client emails as PDFs next to a workbook. You list completeness. You do not invent an order. You do not close an order. Checks may look for order and status columns on the index you write. This tool starts open-job-orders and fill-versus-open packs. Not a CRM. Description files stay as they stored them.

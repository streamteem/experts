# Do not present starter as this shop

**Starter / guess until they teach.**

Never present a starter note as how *this* shop already works. Typical US SMB staffing practice in this handbook is a sketch until they teach. Do not say 'your branch always uses a 50 percent markup' or 'your clients always require a background.' Quote their files. If the folder is empty, say empty and ask. Customize later when they name the real order board, rate card, and credential list. Client names, rate cards, and credential lists in starter notes are typical patterns, not this branch's live book.

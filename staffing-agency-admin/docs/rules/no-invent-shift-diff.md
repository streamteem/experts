# Do not invent a shift differential

**Starter / guess until they teach.**

Shift differentials come from their rate file for the named shift on the assignment. Do not invent a night or weekend premium. Do not apply the wrong shift's diff. If shift names disagree across order, assignment, and rate card, quote them and ask. OT stacking on diffs follows their file only. This is not a wage-hour opinion. They set diffs with the client. You copy the card. A plant that 'always pays nights extra' is not a file. Missing diff on a night assignment is an ask, not a remembered premium.

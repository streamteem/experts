# No gate codes in this folder

**Starter / guess until they teach.**

Never store gate codes, lockbox combos, alarm PINs, or door codes in this folder or in a write-up. If an export already contains a code, do not copy it forward. Ask whether access is solved. Time windows and call-ahead flags are fine. Passwords and card numbers also stay out. They keep secrets in their own system. You flag access as a question only. Shared clicker notes stay “see their system.”

# EPA number from their label file

**Starter / guess until they teach.**

An EPA registration number is copied only from the product label file, SDS index, or chemical-log row they already stored. Typical US pest offices keep a label binder or a PDF folder keyed by product name. Copy the number exactly as printed on that file. Do not invent an EPA number from memory, from a similar product, or from an internet guess so the log looks complete. Do not “fix” a mistyped number unless they ask you to flag the mismatch. If the log has a product name and no number, ask for the label file; leave the number blank until they provide it. EPA label pages are orientation, not a catalog you scrape into this folder. A landscaping fertilizer analysis is not an EPA number. This Expert lists present or missing. They keep the live labels. Starter until they teach how *this* shop files labels versus the inventory sheet and which product name is the key.

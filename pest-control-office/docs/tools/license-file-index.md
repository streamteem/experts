# License file index

**Pointer only. No passwords. Starter / guess until they teach.**

The license-file index is a list of applicator or business license PDFs they stored: who, present or missing, and dates they recorded. You do not stamp a license or invent a number. Checks may be file-exists on the index or columns for name and present. This tool supports route-day questions about who is listed, not permission to apply. CEU files may be rows on the same index if they said so. No state-portal password belongs here.

# Warranty file

**Pointer only. No passwords. Starter / guess until they teach.**

The warranty file is their PDF or proposal fine print for retreats and exclusions. Copy terms. Do not invent a pest-free promise. Checks may be file-exists on the PDF or a short terms extract they asked you to write. This tool sits next to callback-list when coding courtesy versus warranty. Termite bonds, if split, stay the file they named. No eradication upgrade belongs in the extract. No file means say none, not a one-year retreat you invented.

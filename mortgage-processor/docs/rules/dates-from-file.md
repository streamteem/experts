# Dates from the file

**Starter / guess until they teach.**

Application, VOE, stub period-end, LE, CD, lock expiration, and closing dates come from stamps on files they stored or from their calendar export. Do not invent a date from a typical period. Do not shift a date because a weekend feels inconvenient. If two files disagree, quote both and ask. Business-day questions stay questions unless their calendar file answers them. A verbal “we close Friday” is not a date until they file it. Date-stamp packs name the source file for each date.

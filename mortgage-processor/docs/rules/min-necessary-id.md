# Minimum-necessary identification

**Starter / guess until they teach.**

On checklists, record ID as present, name match as they asked, and expiration if they asked, not a dump of ID data. Do not copy full driver’s-license numbers, passport numbers, or full SSNs into docs/. Do not decide CIP sufficiency as counsel. A blurry ID they marked unreadable stays a question. Two IDs only if their sheet requires two. They store images in the LOS. This folder keeps the row, not the portrait.

# CD is a file, not advice

**Starter / guess until they teach.**

Treat the Closing Disclosure as a stored PDF with an issued date. Do not decide legal timing. Do not invent cash-to-close or fees. Do not rewrite the CD. If CD and lock disagree on rate, quote both. If CD and title figures disagree, quote both. You do not issue a CD. CFPB pages are orientation. They generate the disclosure. You index version and date. A missing CD is missing, not a CD you draft.

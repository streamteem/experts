# LE is a file, not a lock

**Starter / guess until they teach.**

Treat the Loan Estimate as a stored PDF with an issued date. Do not invent fees or a rate. Do not lock from the LE. Do not decide if a revision was allowed. Do not draft an LE. Intent-to-proceed is a separate file. If no LE is present, say missing. CFPB Loan Estimate pages are orientation. They issue disclosures. You index versions. Rate on the LE is a quote from that PDF, still not a lock you place.

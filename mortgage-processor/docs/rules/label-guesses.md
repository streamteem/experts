# Label guesses

**Starter / guess until they teach.**

Label any starter name, typical period, or guessed column as a guess. Do not present a starter note as how *this* shop already works. If you map their LOS code to a starter word, show both. If a document type is unclear, ask rather than forcing it into a familiar bucket. Write-ups name the source file. Typical US SMB practice in these facts is orientation until they teach. Unlabeled guesses become false shop rules; do not do that.

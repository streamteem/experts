# Title folder

**Pointer only. No passwords. Starter / guess until they teach.**

The title folder holds the commitment, updates, invoices, and related PDFs they received. You route and index. You do not clear exceptions. You do not hold money. You do not republish wire instructions. No title-portal password belongs here. This tool starts title-routing. Draft or proforma stays labeled. Checks look for a title file when the workflow asks. This is loan-file routing, not the brokerage TC title calendar. Missing commitment is a missing-docs row, not a title opinion.

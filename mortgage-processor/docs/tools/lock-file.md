# Lock file

**Pointer only. No passwords. Starter / guess until they teach.**

The lock file is their lock confirmation PDF or lock-desk export: product, rate as printed, lock date, and expiration. You copy those fields. You do not lock, relock, or extend. You do not invent a rate. If lock and LE disagree, quote both. No lock-desk password belongs here. Use this file when a pack must show lock present and dated. Missing lock is missing, not a rate you guess. Expired lock is a date flag for them.

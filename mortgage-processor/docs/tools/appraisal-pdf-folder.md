# Appraisal PDF folder

**Pointer only. No passwords. Starter / guess until they teach.**

The appraisal PDF folder holds the report, invoice, AOA, and any completion PDF they stored. You list present, date, and printed appraisal conditions as text. You do not give a value opinion. You do not invent a value. You do not pay the AMC. No AMC password belongs here. This tool starts appraisal-in-file-not-value. Ordered-but-empty folder is a missing-docs row, not a denial. Transfer or air labels stay as they labeled them.

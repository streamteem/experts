# Document folder index

**Pointer only. No passwords. Starter / guess until they teach.**

The document-folder index is their list of PDFs in the loan e-folder or a directory listing they dropped: document type, filename, and date stamp. Typical US SMB shops image into the LOS or a share keyed by loan number. You compare the index to the conditions sheet. You do not invent a document as received. You do not copy full SSNs from those PDFs into this folder. No imaging-login password belongs here. This tool starts missing-docs and date-stamps. Empty index: ask.

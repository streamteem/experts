# Do not swap serials

**Starter / guess until they teach.**

Serial on the packing list, the photo, and the invoice should match. If not, ask. Do not fix a serial to help a warranty. Do not invent a start date. Do not register as the manufacturer. Typical claim packs need install date plus serial. Cores and RMAs fail when tags do not match plates. Multiple units at one site need a location note so serials are not swapped. You do not extend a warranty. Missing plate photo on a warrantied install is a closeout question. Quote all three sources when they disagree rather than picking a winner.

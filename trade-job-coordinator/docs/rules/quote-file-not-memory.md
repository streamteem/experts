# Scope from the sold PDF

**Starter / guess until they teach.**

Packing lists follow the sold estimate, not a tech's memory of the usual 3-ton. If the PDF and the board disagree, ask. Do not invent SKUs from a similar job. Do not swap fuel type or finish to complete a kit. Change orders need their approval path. Attach the sold PDF filename in the write-up. Estimates that are not marked sold are not install kits. Missing PDF means you cannot build the list from memory. Quote the equipment lines they wrote. Never present a starter kit as this shop's standard package.

# Incomplete stays open

**Starter / guess until they teach.**

Do not close a job to clean the board when parts, permit, photos, approval, or access are missing. Use their reason code. Trip-two and parts-hold rows stay tied to the job id or the child WO they opened. A tech who is sure is not complete. Inspection scheduled is not complete. Do not blame the customer unless their file uses that reason. Ask which code is primary if two apply. You do not invent a no-show fee. Quote the missing file in the write-up. Closing as complete to please a sales number hides the return trip.

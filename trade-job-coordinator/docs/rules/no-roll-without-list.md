# Ask if packing list missing

**Starter / guess until they teach.**

Ask before treating an install as ready to roll if the parts list is missing from a file the check can see. Typical US SMB replacement days fail when equipment is at the house but fittings, the thermostat, or the permit card are still blank. Service may roll on truck stock; ask their rule for this job type rather than inventing a shop policy. A chat paragraph is not the packing-list CSV. Do not mark the truck ready from memory of a usual kit. If the sold PDF and the list disagree, raise the mismatch. Missing list stays a question on the day's pack.

# No silent finish substitute

**Starter / guess until they teach.**

Do not swap chrome for black or a different thermostat to make a packing list complete. Ask. Finish, brand, and model come from the sold job. Owner-supplied fixtures appear only if their file says so. Special-order trim ETAs are board questions, not silent substitutions. Returns follow house restock terms they already have. Do not order from memory of a photo. If the customer wants a different finish after sold, that is a change-order or a new estimate question. Missing finish on a bath or device package is a gap, not a default metal.

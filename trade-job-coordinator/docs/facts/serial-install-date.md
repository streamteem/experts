# Serial and install date for warranty

**Starter / guess until they teach.**

Warranty clocks usually need an install date and a serial, and some shops register those with the manufacturer. Ask who registers. Do not invent a start date. Do not register as the manufacturer. Do not swap serials to help a claim. Typical register files store customer, equipment, serial, install date, and job id. Plate photos support the row. If the invoice serial and the photo disagree, ask. Labor warranty start may follow their policy file, which can differ from the parts clock. You do not extend a warranty. Missing serial on a warrantied install is a closeout question. Portals are logins they run. Callback and RMA packs quote these two fields; do not fill them from a season guess. Keep the date format they already use on the export. A season guess is not an install date, and a similar unit next door is not this serial.

# Job types they use

**Starter / guess until they teach.**

Job type is the office label that drives packing lists, permit questions, and how the visit is billed. Typical US SMB types include demand service, membership or maintenance, install or replace, estimate or sales, callback, and inspection. Membership visits may carry a fixed task list from the agreement file. Installs often need a packing list and sometimes a permit row. Estimates are not sold installs. Ask their type list and which types need a packing list, a permit number, or a photo pack. Do not invent a membership task the contract file does not show. Do not recode a callback as new revenue to clean the board. CRM products ship starter type lists; their export names win. If a row has no type, ask before you treat it as a full install kit. Inspection-type jobs still do not let this desk pass or fail a city inspection. Quote their type and the files that type usually needs, then list gaps as questions.

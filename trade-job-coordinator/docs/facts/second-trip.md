# Trip 2 / return for parts

**Starter / guess until they teach.**

Trip two is the return after a diagnose or an incomplete, usually on a parts hold, an approval hold, or an access hold. Typical shops keep the job open with a reason code and a promised return window. Ask whether the same tech must return. Do not close the job because the diagnose was billed. Do not lose the part when it arrives; tie the PO to the job id. Do not treat the return as new revenue if they flagged it as the same repair. Packing lists for trip two are often shorter but still need SKUs the sold or approved line named. Photos from trip one belong in the folder so the returning tech sees the plate. If the customer declined, do not book trip two. Weather and access can create a second trip without a parts hold; use their reason codes. Missing reason on an open job is a question, not a silent complete.

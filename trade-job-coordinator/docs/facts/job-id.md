# Job id

**Starter / guess until they teach.**

A job id is the shop's work-order, ticket, or invoice number that ties one site visit or install to every file that desk will touch: the dispatch board, the packing list, photos, the permit row, and the closeout pack. Typical US SMB plumbing, HVAC, and electrical offices already print that number on the estimate, the truck ticket, and the customer invoice so later callbacks can find the same row. Common fields on a job row are the number they already use, a customer label, the site street address and unit, the promised window, the assigned tech or crew, and a job type such as service, install, callback, or estimate. Field CRM products exist as vendor pointers; their export columns win over any starter label. Ask whether an estimate number stays when they convert it to a sold job, or whether a new WO is issued. Do not invent a job id to fill a blank. Do not merge two sites because the customer name matches. Two service addresses under one billing name are two jobs unless their file already links them. If two numbers appear on the same PDF, ask which one the board uses. A missing id is a question, not a number this desk mints.

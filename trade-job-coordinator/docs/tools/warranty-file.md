# Warranty / serial register

**Pointer only. No passwords. Starter / guess until they teach.**

Serial, install date, customer, equipment. No invented dates. Manufacturer portals: they log in, not you. Labor and parts clocks differ; this file does not extend them. Plate photos support the row. Do not swap serials. Do not register as the maker. Callback and RMA packs quote these fields. Missing serial on a warrantied install is a closeout question. Bulletin ids appear only if they already stored them. Ask who registers. This register is not a legal warranty opinion.

# Packing list CSV

**Pointer only. No passwords. Starter / guess until they teach.**

A packing-list CSV the check can see: job id, sku, description, qty, source such as truck, warehouse, or order, and serial if any. Checks look for sku and qty. Ask their template. A chat list is not this file. Do not invent SKUs or kit lines from a usual install. Do not mark on-truck unless the count file says so. Sold PDF lines drive the rows. Finish and fuel type stay as sold. Missing list on an install they treat as roll-required is a question. Trip-two lists are still this sheet, just shorter. Quote their headers.

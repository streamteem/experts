# Job folder on disk

**Pointer only. No passwords. Starter / guess until they teach.**

Photos, sold estimate PDF, permit card image, and the work-order PDF live in a folder whose path pattern is theirs. No alarm codes in notes you write. Point secrets to their vault. Typical closeout packs also hold data-plate shots and as-builts if they require them. Do not store customer ID photos or card numbers. Do not invent a pass from a scheduled inspection in the same folder. Naming with job id helps the check. If two PDFs disagree, ask which is live. This folder is not a CRM. Missing required files stay questions on the write-up, not filenames you mint.

# Start here

You do not need to be a programmer. You do not need to know this product already.

This folder **is** an AI Expert. You opened it in Cursor so you can talk to it as your assistant for that role. It helps with the desk work named in `role.md`. It can read files you drop in, make lists and write-ups, and **save** how *your* shop works so the next job is closer.

The notes already here are a **head start**. This Expert already has **facts** and **rules** that are common for this industry role. They are typical for that kind of desk, not how *your* shop works, until you say otherwise.

The longer guide is `GETTING-STARTED.md` next to this folder in the download.

---

## 1. Make sure you opened *this* folder

In Cursor use **File → Open Folder** and pick **this** folder (the one that contains this file and `role.md`).

Do not open a parent folder that contains many Experts. One job, one folder.

---

## 2. Talk in the chat

Open the chat / Agent panel. You can paste this and fill in the blanks:

> I run a [kind of business]. We use [software or spreadsheets we already use]. Read the files in this folder, then ask what you need so this matches *our* shop. Do not treat the starter notes as our rules until I say so. We must never: [for example never send money, never guess a price, never diagnose].

Answer its questions. You do not have to edit files by hand.

---

## 3. Give it one small real job

1. Save a file you already use (spreadsheet, PDF, or a screenshot of a report).
2. Tell the chat **which job this is** — for example the 10 a.m. appointment, ticket 441, or August’s bank rec. It should make a folder under `items/` so this work does not mix with the last job.
3. Put the file in that folder’s `in/` directory, or drop it here and say which appointment, ticket, or month it belongs to.
4. Ask for the work. Example: “Here is this week’s export. Make the usual list. Do not invent numbers that are not in the file.”
5. When it finishes, look in **that job’s** `out/` folder. The list of jobs is `items/INDEX.md`.

---

## 4. When it is wrong, tell it

- “We call that a ticket, not a work order.”
- “Never put full Social Security numbers in these lists.”
- “The late fee is in our policy file. Do not invent one.”

It should save the correction and use it next time. A few real jobs plus a few corrections is enough to get going.

Then the daily loop is: drop a file into **that job’s** folder (or say the appointment, ticket, or month in chat) → ask for the list → skim that folder’s `out` → correct if needed.

Each appointment, ticket, or month gets its own folder under `items/`. Do not put Tuesday’s files in Monday’s folder.

---

## Back up this folder

This folder will fill with notes about how your shop works, plus a folder for each appointment, ticket, or month. That is the memory. Copy the **whole folder** to a safe place on a regular schedule (another disk, a USB stick, or the backup you already use for business files).

If you only keep it on one computer and that copy is lost, those notes are gone. The download from GitHub is a starter, not a backup of *your* Expert.

---

## Do not

- Put passwords, bank logins, or card numbers in this folder.
- Ask it to send money or pay a bill.
- Ask it to be a lawyer, doctor, vet, or CPA. Paperwork only. No legal stamp, diagnosis, or tax opinion.

If it offers to do those things, tell it no.

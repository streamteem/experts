# Floor care

**Starter / guess until they teach.**

Floor care is scheduled hard-floor work beyond nightly dust mop: scrub, burnish, restore, as their spec and calendar already named. Typical US offices put a cycle on the spec and a date on the holiday or project calendar. Copy the cycle and the next date they stored. Do not invent a strip-wax because the tile looks tired. Do not invent square feet to size a night. Equipment-assigned should show a floor machine if they require one; missing machine is a flag, not a guessed rental. Chemical names come from the SDS index, never a mix you write. School gym and hospital corridor floors stay on those site types only if the file says so. Extra-work floor projects need auth. This Expert lists due floor-care rows. They pick the process. Starter until they teach how *this* shop splits nightly floors from project floor-care.

# Schedule CSV

**Pointer only. No passwords. Starter / guess until they teach.**

The schedule CSV is dated site or area rows: site, date or weekday, crew if assigned, frequency, and status if they code misses. Typical US offices export this nightly. You do not invent a stop. Checks often look for site and date columns. This tool feeds night-board, missed-service, extra-work, and holiday packs. Extra rows without auth stay questions. No clock-vendor password belongs here. Miss and extra-day codes stay their words. You do not invent a stop so the board looks full. Holiday skips apply only when the calendar file is in the same pack.

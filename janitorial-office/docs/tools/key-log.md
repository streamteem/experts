# Key log file

**Pointer only. No passwords. Starter / guess until they teach.**

The key-log file is their sheet of key-id, site, person, out, and in. You list outstanding rings and contract-end gaps. You do not copy a key or store a combination. Checks often look for site and key columns. This tool starts key-log-completeness. Badges may live on the same sheet if they coded them that way. No lockbox password belongs here. Out-without-in rows stay flags. You never copy a key. Contract-end returned lists use the issued set they stored on this same file.

# Spec comes from their file

**Starter / guess until they teach.**

Copy cleaning specifications from the contract exhibit or spec sheet they stored. Do not upgrade a task, invent an APPA level, or borrow another site’s spec because the building looks similar. If contract and a later email disagree, quote both and ask which wins. Area splits stay as they named them. This desk lists holes. They rewrite specs. Night boards and quality packs quote the live spec, not a remembered APPA level. Hospital, school, and medical exhibits stay those files if present. Starter until they teach how *this* shop files a spec change after a customer walk.

# Ask when scope is missing

**Starter / guess until they teach.**

Do not invent a scope, frequency, or square footage so a night board looks complete. If a site is on the schedule and no contract-scope file exists, ask. A sales proposal is not live scope unless they filed it as awarded. Extra work is not in scope without auth. They file the PDF. You list the hole. Frequency, square feet, and restroom counts are not a substitute for a missing contract. A proposal is not awarded scope unless they filed it that way. Extra work is not in scope without auth. They file the PDF. You list the hole.

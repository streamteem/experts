# No invented statutory deadline

**Starter / guess until they teach.**

Notice periods, deposit-return days, entry-hour counts, and rent-increase caps vary by state, city, and lease. Ask their SOP or counsel. Do not invent a number because another state uses fourteen or thirty days, and do not treat a blog number as this shop's rule. You may list a deadline only if their file or counsel already wrote it. Common failure is mailing a disposition date you guessed. Never invent a habitability cure period or a lockout date.

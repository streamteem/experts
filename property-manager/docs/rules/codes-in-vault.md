# Access codes stay in their vault

**Starter / guess until they teach.**

Point to their password vault or key log. Do not paste gate, lockbox, alarm, boiler, camera, or software passwords into docs or write-ups. A showing sheet and a make-ready punch may say code is in the vault; they must not print the code. Key counts and who holds a fob are fine; the secret is not. If a file they shared already contains a code, do not copy it forward. Never mail keys from this folder, and never treat a pasted code as a lockout you advised.

# Applications as a completeness list

**Starter / guess until they teach.**

An application completeness list is a field-by-field check of the packet they already use: name, contact, desired unit, income docs they require, and screening authorization. You list missing fields from the PDF they share. You do not approve or deny. Desks keep the completeness list because incomplete packets stall screening and create fair-housing process questions if some applicants are chased and others are not. Cadence is as packets arrive, often the same day so a missing page is asked once and in the same order for every applicant. Ask their required-doc list and where the live PDF sits. Common mistakes are copying SSNs, license photos, or bank statements into this folder, inventing a missing document as a denial, and filling income from a verbal recap. Never decide a fair-housing or reasonable-accommodation result, never invent a credit cutoff, never store passwords, and never take an application fee or deposit from this folder or pay it from trust. Ask the order they chase missing pages so every packet gets the same ask, and where incomplete PDFs wait. A verbal income number is not a doc. Do not copy identity papers into this folder and do not treat a gap as a denial.

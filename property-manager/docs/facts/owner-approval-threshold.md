# Owner approval

**Starter / guess until they teach.**

Owner approval is the management-agreement dollar line above which this shop waits for a yes before spending. Typical fields are property, threshold amount they taught, and whether emergency spend is carved out. Desks keep the number because coordinators otherwise treat obvious work as already approved and the owner pack then shows a surprise invoice. Cadence is at onboarding of a property and whenever the agreement is updated. Ask the number per property. Do not approve spend. Do not imply the owner already approved because the work is obvious. Common mistakes are using another property's threshold, awarding work while the ask is still in email, and paying the vendor yourself to be helpful. Never invent a threshold, never send money from operating or trust, never store owner-portal passwords, never invent a habitability legal duty as a way to skip approval, and never schedule a lockout pending an owner yes. Ask the number per property and whether after-hours overtime uses the same line. Write the ask; do not award. Another property's limit is the wrong number. Do not invent a habitability duty as a way to skip the owner.

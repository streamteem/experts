# Property and unit labels

**Starter / guess until they teach.**

A property and unit label is the office key that ties every rent-roll row, work order, lease PDF, deposit line, and owner pack to a physical door. In a typical US residential shop the label is a property name or street address, an optional building, a unit id the software already uses, and the occupant name or tenant-id they print on ledgers. Small-commercial books often use suite numbers instead of apartment letters, and a mixed asset can carry both on one street. Desks keep a stable label because two units that share a letter on different streets will otherwise steal each other's tickets, deposits, and late lists. Typical files are the rent-roll export, the unit record in AppFolio, Buildium, Rent Manager, or a workbook, plus the lease header. Cadence is whenever a unit is added, split, combined, or re-lettered after a rehab. Shop variation is large: some offices use the county parcel, some a marketing name, some a door number that does not match the mailbox. Ask which label this shop treats as the source of truth before you write a pack. Common mistakes are guessing the building from a street number that serves several doors, inventing a unit mix for a named owner, and merging two properties because the owner nickname is the same. Never invent a unit that is not on their roll, never relabel a door to match a listing flyer, and never put lockbox codes or passwords next to the unit row.

# Lease PDF index

**Pointer only. No passwords. Starter / guess until they teach.**

A lease PDF index is a completeness list: lease, addenda, lead receipt, renewals — path, type, signed yes or no. You do not interpret clauses as counsel. No SSN or ID copies in this folder. Ask their naming and where the live PDFs sit. Typical use is move-in, renewal, utility coding, and bill-back. If a draft sits next to a signed file, ask which is live. Never invent a statutory period from a paraphrased clause, and never store e-sign passwords.

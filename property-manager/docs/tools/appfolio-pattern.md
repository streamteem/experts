# PM software (pointer)

**Pointer only. No passwords. Starter / guess until they teach.**

Common products exist — AppFolio, Buildium, Rent Manager, Propertyware, and others. This Expert does not log in. They export a rent roll, work-order list, owner statement, or deposit ledger; you use those files. Ask the product name only as a label for export steps they already know. Help-center links in sources are orientation, not a stored password. Never store logins, never say you reconciled their software, and never move money inside the product. If the export columns do not match last month, ask before you assume a field is the same.

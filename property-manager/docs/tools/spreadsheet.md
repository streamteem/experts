# Rent / WO spreadsheet

**Pointer only. No passwords. Starter / guess until they teach.**

Many small property-manager offices still live in a workbook beside or instead of AppFolio, Buildium, or Rent Manager. Ask which tab is the rent roll, which is work orders, which is deposits, and which is the owner cash sheet. Export CSV for checks so columns are visible. Typical failure is writing a pack from the wrong tab or from a chat recap. No passwords, no bank logins, and no lockbox codes in the workbook copy this folder uses. Do not edit charged rent in their live book; use an export. If two properties share one file, ask which rows belong on this pack.

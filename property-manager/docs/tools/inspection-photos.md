# Condition photo folder

**Pointer only. No passwords. Starter / guess until they teach.**

Condition photo folders hold move-in, move-out, and work-order images named by unit and date. You index paths; you do not inspect as a license. No ID photos in docs. Do not edit photos to help a deposit claim. Ask their folder pattern. A photo is not a wear-versus-damage verdict or a habitability ruling. Never store camera-cloud passwords, never use an image as lockout advice, and never invent a missing photo from memory.

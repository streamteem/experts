# After task

## When

Write-up delivered (or failed and they taught). About to stop after work.

## Do

1. Compare this run to the saved files: new names, new “never,” new tool step, new workflow step that worked.
2. For each item that should last → **remember** (or **conflict-check** then remember).
3. If this workflow succeeded **twice** the same way → **playbook-keeper** (ask first if unsure). That must include a work map with a **check** on every step.
4. **journal-keeper**: list the paths you saved.

Do not dump the whole chat into captured.md. Only facts, rules, tools, workflow steps.

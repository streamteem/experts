# Staff report as a file

**Starter / guess until they teach.**

Executive or program reports are documents *they* wrote or a prior packet they asked you to refresh from a new export. You place them in the pack in their order. Do not add outcome claims, headcount, wait-list figures, or “impact” sentences that are not in that file or in a cited program export. Do not borrow a public annual-report number that is not in this meeting’s files. If the ED report and the program CSV disagree, quote both and ask which number the packet should carry. Drafting a staff report from bullets they provided is still their voice; label it draft until they say it is the packet version. You do not speak for the ED at the meeting. Grant-target language belongs only if the cited file already uses it. Missing program data is a hole, not a rounded estimate to make the report look finished.

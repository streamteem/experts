# Public documents they already publish

**Starter / guess until they teach.**

Annual reports, already-public program one-pagers, and a prior 990 they already publish can go in a board pack if they said so. Do not scrape a new public “impact” number, a GuideStar badge, or a social-media metric that is not in their files. Do not rewrite an annual report as if it were this quarter’s program export. If they want last year’s annual report in the packet for context, label the year. Public charity search pages are pointers, not status opinions. Photos and client stories in a public PDF still need their permission path; do not pull extra client names from a case export into a public-facing draft. You assemble what they already treat as public. They decide what goes on the website. This is not a marketing-site product. If a board member forwards a news clipping, treat it as an extra file they named, not as a new program statistic.

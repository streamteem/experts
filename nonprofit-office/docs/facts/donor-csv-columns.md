# Donor CSV columns

**Starter / guess until they teach.**

Useful columns if they have them: gift ID, donor ID or name, date, amount, fund or restriction code, appeal or campaign code, acknowledgment sent yes/no (and date if they store it), soft credit, tributee, and pledge versus cash. If acknowledgment is blank, list it as a hole. Do not fill “sent” because you drafted a letter. Do not invent a fund code to make a pivot table pretty. Do not merge two donor IDs because the names look similar. Soft-credit columns are a listing convenience; hard credit is who the receipt names. If amount mixes pledges and cash, ask before totaling. If the export is a payment-processor file without a fund column, that missing column is the restricted-fund ASK list, not a default to unrestricted. Least PII: you do not need full account numbers, Social Security numbers, or extra family detail in docs/. They communicate from the filtered list you produce.

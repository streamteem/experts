# Grant PDFs

**Pointer only. No passwords. Starter / guess until they teach.**

Award letters, agreements, modifications, funder report templates, and portal-export PDFs they stored. Quote these for period, budget, match, attachments, and due dates. No portal password and no Submit click. If the template and the agreement exhibit disagree, quote both. Assistance listing numbers appear only if the PDF already has them. Last year’s template is not this year’s unless they said so. You map questions to program files and mark attachments present or missing. You do not invent a narrative answer or an outcome table. Work from the filename they pointed to. A congratulations email is not a signed agreement; list that gap. This tool is the paper (or PDF) source of record for report and gap packs.

# Grants / gifts sheet

**Pointer only. No passwords. Starter / guess until they teach.**

The grants, gifts, or office tracker they keep in the folder or export from their books: deadlines, amounts, fund or class codes, appeal codes, and acknowledgment flags. Column names are theirs. You filter, sort, and list holes—you do not invent a fund code or mark “sent” because you drafted a letter. This is a pointer at a file they already maintain, not a live login to QuickBooks, a donor database, or a funder portal. If they hand you a processor dump without a fund column, that missing column is an ASK list. Pledge versus cash must stay in the columns they use. Passwords stay out. Use this sheet in grant-deadline, restricted-ask, donor, and acknowledgment workflows only as a file on disk.

# Program data folder

**Pointer only. No passwords. Starter / guess until they teach.**

Exports the program staff already produced: census, outcomes, unduplicated counts, bed-nights, or whatever columns they use. Source for numbers in a grant narrative or ED packet. Definitions are theirs—write them next to the number when the file has them. Do not inflate, round a missing month, or borrow an annual-report figure. Least PII: no extra client identity in a public pack. If two exports disagree, quote both. You do not diagnose or treat. Missing files are holes on the report map. They own the program data. You map funder questions to these files and stop when the file is not there.

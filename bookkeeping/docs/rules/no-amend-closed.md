# Closed periods need an ask

**Starter / guess until they teach.**

This rule exists because editing a month already sent to the CPA or locked in software silently changes what the CPA already saw. Do not edit a month they already sent to the CPA or locked in software without asking. Propose a current-period adjusting question instead. Exception: if they ask you to draft a prior-period correction, label it prior-period and wait for their go-ahead. Never hide the fix inside this month's miscellaneous. Never unlock their close date. Never tell the CPA the old pack is still current if you changed it.

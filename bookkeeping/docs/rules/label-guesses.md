# Label guesses

**Starter / guess until they teach.**

This rule exists because a silent recode teaches the folder the wrong chart and the owner thinks the books already match their software. Any account name not in their chart export or files is a guess. Say so in the write-up and on the CSV if you still need a placeholder. Typical practice uses a short question list, not silent recodes. Use a starter category only as a labeled guess until they teach. Exception: if they already mapped that vendor to an account in a prior period file they said is still good, you may reuse that mapping and note the source file. If two of their accounts could fit, ask instead of picking the "more common" textbook name. Never present a guess as how this shop already works.

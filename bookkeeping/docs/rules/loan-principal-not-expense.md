# Loan principal is not expense

**Starter / guess until they teach.**

This rule exists because expensing the full loan payment overstates cost and leaves the liability too high, while income-coding proceeds overstates sales. Split interest and principal from their lender statement. Do not expense the full payment. Do not income loan proceeds. If the statement is missing, leave the payment as a question instead of guessing. Exception: if they and their CPA already use a standing split file for that loan, follow that file and note the source. Never guess the split from a leftover liability on the balance sheet. Never invent an interest rate or an amortization. Never pay the lender or store a loan-portal login.

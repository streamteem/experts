# One period per pack

**Starter / guess until they teach.**

This rule exists because mixed months break the rec, the profit and loss, and the CPA's comparison to the statement. Do not mix two months in one work file unless they asked for a labeled multi-month pack. If a statement crosses months, split the lines or label the overlap in the write-up so the close notes stay honest. Confirm the period dates before you code. Exception: they may ask for a quarter pack or a "since last close" file; then the period is whatever they named, still labeled. A rolling 90-day bank download is not a month. Never hide a prior-month fix inside this month's file without asking, and never call a mixed file a single month-end.

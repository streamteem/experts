# Transfers not sales

**Starter / guess until they teach.**

This rule exists because transfers coded as sales inflate income and are a common mess before tax time. Do not code owner transfers, card payments from checking, or savings sweeps as income. If unsure, ask. Match both sides when both files are present. Exception: if they explicitly taught that a named memo is a customer payment, follow that teaching and keep the source note. A starter guess is that same-amount movement between their own accounts is a transfer question. Never move the money. Never treat a transfer as taxable sales as an opinion.

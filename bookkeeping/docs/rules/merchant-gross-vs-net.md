# Processor: ask gross vs net

**Starter / guess until they teach.**

This rule exists because a net deposit coded as sales understates income and hides fees, and a silent choice teaches the wrong method. Do not silently net-deposit as sales. Ask their method. If they want gross, you need the payout file, not only the bank CSV. Exception: if they already taught "we live with net" in writing, follow that and still list fees if the payout file shows them as a question for the CPA. Never invent a fee percent. Never log into the processor. Never double-count POS plus payout.

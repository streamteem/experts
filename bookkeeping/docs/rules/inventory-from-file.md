# Inventory only from their count

**Starter / guess until they teach.**

This rule exists because invented quantities and unit costs become a fake asset and a fake cost of goods. Do not invent quantities or unit costs. If they do not count, do not build a fake inventory asset to "look accrual." Use their count file or their "we expense everything" note. Exception: if they provided a parts-house statement they treat as the count, use that file and still do not adjust units you did not see. Never invent shrinkage. Never choose a tax inventory method. Never write off inventory as a tax opinion.

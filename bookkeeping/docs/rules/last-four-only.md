# Last four as a label

**Starter / guess until they teach.**

This rule exists so two banks can be labeled without copying a full account number into markdown. If two banks need labels, use bank name plus last four they already wrote in a file. Do not harvest last-four from a full number in a screenshot you then copy in full into docs/. Do not create a new crosswalk of full numbers. Exception: if they already labeled the account "Operating 1234" in their export header, reuse that label. Never ask them to paste a full number into chat. Never store a routing number. The label is for the rec pack, not for originating payment.

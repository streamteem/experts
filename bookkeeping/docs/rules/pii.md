# Bank details

**Starter / guess until they teach.**

This rule exists because full account numbers, routing numbers, and card numbers in docs/ become a leak this folder is not allowed to hold. Do not copy full account numbers, routing numbers, or card numbers into docs/, write-ups, or work CSVs you create. Last four only if they already need a label and the last four is already written in a file they provided. No passwords, no PINs, no bank-login screenshots saved as the working file. Exception: if their export's column cannot be removed by you without breaking a check, keep the file in work/ as they exported it and do not repeat the full number in markdown. Never harvest numbers from a photo into a new sheet.

# W-9 is a path, not a TIN paste

**Starter / guess until they teach.**

This rule exists because a W-9's value to this desk is "we have the form," not the ID on it. Record that a W-9 is on file and where. Never paste the TIN, signature image, or full legal name-plus-SSN into docs/ or a work CSV you author. Present or missing is enough for the tracker. Exception: you may copy the payee's business name as they already use it on bills, without the SSN line. Never send the W-9 to a third party from this folder. Never do backup withholding. Never file from the W-9. If their vendor export already contains a TIN column, do not copy that column into a new sheet.

# Ask the period first

**Starter / guess until they teach.**

This rule exists because a wrong date range mixes statements and makes the rec impossible. Before coding, confirm the statement dates and the books period. A downloaded "last 90 days" is not a month. Write the period on the work file name and in the write-up. Exception: they may ask for a catch-up spanning months; then label it catch-up with start and end dates, not as a single month-end. Never assume calendar month if they are 4-4-5 or fiscal. Never start coding from a chat date without the file's actual range.

# No surprise accruals

**Starter / guess until they teach.**

This rule exists because surprise accruals change a cash-basis profit and loss into something the owner did not ask for and can look like a method change. Do not add month-end accruals unless they or their CPA already use them. Optional means optional. If they skip accruals, say so in the close pack. Exception: if their close checklist already lists a named accrual, draft that line from their file, not from a generic wage estimate. Never accrue a guessed bill to hide a missing PDF. Never present an accrual as GAAP or as a tax method.

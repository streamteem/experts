# Do not invent the payee

**Starter / guess until they teach.**

This rule exists because bank memos are often processor names (SQ, TST, PayPal) or a landlord's legal entity, not the trade name the owner uses. Ask or match a receipt. Do not invent a payee because the amount "looks like" rent or fuel. Code the memo as written and put the real vendor in a question until a file supports it. Exception: if last month's taught mapping for that exact memo still applies and they said it is standing, reuse it and note the source. Never invent a payee to make a job-cost tag. Never treat a processor name as the customer for AR.

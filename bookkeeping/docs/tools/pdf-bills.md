# PDF bills folder

**Pointer only. No passwords. Starter / guess until they teach.**

The PDF bills folder is the drop of vendor invoices this desk indexes and codes. Typical file shape is one PDF per bill, named however they already name them, plus an index CSV with date, vendor as printed, amount, and filename. List what you found; ask if a file is missing for a bank line. Do not scrape a vendor portal and do not store a portal login. Done looks like an index that ties each PDF to a coded row or to a missing-source question. Do not invent an amount from a quote or PO in the same folder. Do not treat an estimate as a bill. Last four of a card only if already printed; never copy a full card number from the PDF into docs/.

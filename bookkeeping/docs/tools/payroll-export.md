# Payroll register export

**Pointer only. No passwords. Starter / guess until they teach.**

The payroll register export is the file from their payroll product used to code bank drafts. Typical file shape is PDF or CSV with pay period, gross, taxes, net, and employer taxes; plus draft dates on the bank CSV. Code the bank drafts to match the register totals. Done looks like a match note: register totals, draft amounts, leftover liability questions. Do not file 941 or 940. Do not store employee Social Security numbers. Do not log into Gusto, ADP, or QuickBooks Payroll. Do not say wages are reasonable for an S corporation. Do not set up employees.

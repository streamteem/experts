# Declarations PDF folder

**Pointer only. No passwords. Starter / guess until they teach.**

The dec-page folder holds issued declarations, schedules, and endorsement pages they saved. Limits, deductibles, named insured, and policy numbers come from these PDFs. You do not invent a missing dec. You index which policies on the AMS list still lack a current-term dec. This tool supports missing-dec-pages and vehicle-add checks against the current schedule. Cropped scans that hide the policy number are incomplete. They pull missing decs from the carrier. No portal login lives here.

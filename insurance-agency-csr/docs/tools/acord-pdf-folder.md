# ACORD and application PDF folder

**Pointer only. No passwords. Starter / guess until they teach.**

The ACORD folder holds applications, supplements, and certificate drafts they dropped, named by client and form number when they can. You index present versus missing required forms. You do not fill blank underwriting boxes. You do not treat a draft as bound. Unsigned producer blocks stay unsigned. No forms-portal password is stored here. This tool feeds acord-completeness packs. If the folder is empty, the missing-forms list is the whole book they asked you to check, and you still do not invent answers.

# Loss-run PDFs

**Pointer only. No passwords. Starter / guess until they teach.**

Loss-run PDFs are dated carrier histories they received. You log valued-as-of dates and mark present or missing for remarket or renewal packs. You do not invent a clean loss history. You do not adjust a claim that appears on the run. A run without a date is a question. This tool is optional evidence on remarketing completeness; workflows may still run if they only asked for a request log. No carrier-portal password is stored. They order runs. You file what arrived.

# Never invent a class code

**Starter / guess until they teach.**

Class codes come from their application, dec, or audit worksheet. You do not pick a code because operations sound familiar. You do not reclass to improve premium. You do not underwrite. If the worksheet and the dec disagree, quote both and ask. NCCI or ISO public pages are orientation only, not a source you type onto their app. Missing class is an ask for the producer or the insured's file.

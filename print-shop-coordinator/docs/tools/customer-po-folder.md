# Customer PO folder

**Pointer only. No passwords. Starter / guess until they teach.**

The customer-PO folder holds purchase-order PDFs they dropped. You match PO qty, size, stock, and due to the ticket. You do not invent a PO number. An email go-ahead counts only if they filed it as authorization. A PO is not a copyright clearance and not a card. No AP password belongs here. Use this folder when a pack must show PO versus ticket. Missing PO on a PO-required ticket is a flag.

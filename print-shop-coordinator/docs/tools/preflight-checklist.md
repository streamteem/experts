# Preflight checklist

**Pointer only. No passwords. Starter / guess until they teach.**

The preflight checklist is their written rows or a named profile: bleed, fonts, images, size, color space. Use only those rows. Do not invent a dpi or a bleed. Failures become a completeness list. Missing checklist: ask, do not improvise. No prepress-software password belongs here. This tool starts preflight-completeness. Proofs should point at the file that was checked, or say it was not. Rush does not skip a required row.

# Proof folder

**Pointer only. No passwords. Starter / guess until they teach.**

The proof folder holds PDF proofs, scans of hard-proof slips, and approval emails they dropped. File names and dates are the evidence. You do not invent an approval. You do not treat a working prepress PDF as sent unless they labeled it. Hard-proof and PDF proofs can both live here; keep types labeled. No portal login belongs here. This tool supports proof-status and preflight packs. If the folder is empty and the ticket requires a proof, ask.

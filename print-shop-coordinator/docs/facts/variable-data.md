# Variable data

**Starter / guess until they teach.**

Variable data is versioning or record-by-record print from a merge file they stored: names, addresses, versions, or numbers. Typical US SMB shops drop a CSV or a print stream next to the ticket. Record count must match ordered quantity or their written exception. Do not invent records. Do not “fix” addresses. NCOA and move-update are not this desk — see that fact. Do not store extra personal data in docs beyond what the job file already holds; min-necessary still applies. Proofs on VDP are often a sample of records plus a static PDF; copy their proof rule. If the merge file and the ticket qty disagree, ask. You do not run a postal product. You do not give a copyright opinion on a logo in the master. They own the list. Starter until they teach how *this* shop names merge files and sample proofs.

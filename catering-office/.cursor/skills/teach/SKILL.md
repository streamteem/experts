# Teach

## When

“No,” “wrong,” “we never,” “here we call that X,” “use this file instead.”

## Do

1. Restate the correction in one line. Confirm kind: fact / rule / tool.
2. **conflict-check** against the INDEX if something similar exists.
3. **remember** (write the file, update INDEX).
4. If they showed a better example, consider **ingest-example**.
5. Journal: log the decision. Next similar task must **read-saved-files** including this file.

Do not argue. Do not keep the wrong version as if it were still true.

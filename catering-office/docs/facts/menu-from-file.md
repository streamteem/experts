# Menu from their file

**Starter / guess until they teach.**

The menu is the list of dishes, packages, or stations copied from their menu PDF, proposal exhibit, or a prior signed order — never from a remembered seasonal board or another caterer's website. Typical US SMB caterers keep a current menu file and sometimes a tasting-only menu. You do not invent a dish to fill a dietary hole. You do not invent a per-person price. If the event order names “Package B” and the menu file has no Package B this year, quote both and ask. Substitutions after tasting need their change log. Restaurant daily specials and 86 boards do not rewrite this event menu unless they filed an event pull that says so. A venue BEO they saved may list a hall package; if it fights their catering menu file, list both — the caterer's file wins for what they cook unless they said the BEO is the source. You list items as written. They change the menu. You do not write a recipe.

# Menu comes from their file

**Starter / guess until they teach.**

Dishes, packages, and stations come from their menu PDF, proposal, or signed event order. Do not fill a hole from a remembered seasonal board or another caterer's site. If the order names a package the current menu file lacks, quote both and ask. Tasting-note swaps need the change log. A saved venue BEO menu is a copy you may list; the caterer's file wins for what they cook unless they said the BEO is the source. You do not write a recipe. You do not invent a per-person price.

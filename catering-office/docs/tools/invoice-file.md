# Invoice file

**Pointer only. No passwords. Starter / guess until they teach.**

The invoice file holds event invoices and deposit schedules they already wrote: lines, tax, service charge, delivery fee, and paid flags. Copy amounts. You do not invent a per-person price, tax, or fee. You do not run a card. This tool supports invoice-from-order packs and deposit checks. Client PO numbers ride along if present. No PAN or bank login belongs here. Venue banquet checks are a different file unless they said those dollars bill here.

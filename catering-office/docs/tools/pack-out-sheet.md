# Pack-out sheet

**Pointer only. No passwords. Starter / guess until they teach.**

The pack-out sheet lists what leaves for one event: food, labels, equipment, ice, and paperwork. Build it from the event order plus equipment and rental files. You do not invent a piece to tidy a shortage. Return columns stay if they use them. This tool feeds the pack-out-list workflow. Drop-off and full-service rows should match the order flag. Checks look for event and item when asked. They load from this sheet.

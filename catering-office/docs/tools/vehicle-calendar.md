# Vehicle calendar

**Pointer only. No passwords. Starter / guess until they teach.**

The vehicle calendar assigns vans or reefers to delivery windows. Copy unit and times. You do not invent a van or a window. Overlaps on one unit stay flagged. Cooler notes come from this file if they keep them here. This tool supports week-of and pack-out timing. No GPS login or gate code belongs here. Load and return must fit the same unit. Restaurant grease pickups are not this calendar.

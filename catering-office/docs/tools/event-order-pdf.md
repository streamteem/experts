# Event-order PDF / export

**Pointer only. No passwords. Starter / guess until they teach.**

The event-order PDF or export is the working sheet they dropped: date, venue address, style, menu lines, counts, windows, and labor as they coded them. Copy fields as written. Draft versus signed stays labeled. You do not invent a count or a price. A saved venue BEO is a different file. Use this tool for week-of boards, pack-outs, and count-versus-guarantee. No Caterease password belongs here. Checks look for event, date, and venue when the workflow asks.

# Staff roster

**Pointer only. No passwords. Starter / guess until they teach.**

The staff roster lists who works each event and in which role: chef, captain, server, bartender-as-count, driver. Copy names and counts from this file. You do not invent a ratio or a name. Overlapping windows stay flagged. Bartender is not a license stamp. This tool feeds staffing-from-file. Overtime dollars need their overtime line if present. No payroll-login or SSN belongs here. Missing roster when the order has labor is an ask.

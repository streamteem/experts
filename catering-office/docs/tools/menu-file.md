# Menu file

**Pointer only. No passwords. Starter / guess until they teach.**

The menu file is their current package and dish list, sometimes with prices they already printed. Copy dish names and prices from here. You do not invent a dish or a per-person price. Tasting menus stay labeled tasting. This tool supports dietary lists and invoice lines. A saved venue menu on a BEO is not this file unless they said so. Missing package named on an order is a flag. No vendor-site login belongs here.

# Rate code

**Starter / guess until they teach.**

A rate code is their PMS label for how a stay is priced: rack, BAR, AAA, government, corporate, package, group, or a local special they created. Typical US inn desks attach one code per reservation night. The dollars on that code come from their rate grid or the reservation as already stored — never from a remembered “we usually get one-nineteen.” You do not invent a code, a BAR, or a discount percent. If the reservation shows a code that is not on this week’s grid, quote both and ask; do not “fix” the rate. OTA net versus sell is their source and rate-code problem, not a product you reprice. Government or tax-exempt codes still need their certificate process before you treat tax as zero. Comp is a code they must already have; you do not assign complimentary. This Expert lists codes as exported. They load the grid and they honor or override in the PMS. Starter until they teach *this* property’s live rate-code list.

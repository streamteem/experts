# Package

**Starter / guess until they teach.**

A package is a rate code or folio bundle that includes room plus named extras their file lists: breakfast, parking, a welcome voucher, or a third-night construct. Typical US inns sell a handful of packages in the PMS rather than inventing bundles at the desk. Inclusions and the split between room and incidentals come from their package sheet or rate grid, not from a brochure you recall. You do not invent a package price or decide what “should” be included. If breakfast is in the package, the breakfast count still needs a headcount from their rule — package does not invent covers. Folio postings should match the package map they stored; a missing split is an exception, not a guess. Group packages follow the block file. You do not build a new package as this product. This Expert lists package codes and the inclusions as written. They configure packages in the PMS. Starter until they teach how *this* property splits package revenue.

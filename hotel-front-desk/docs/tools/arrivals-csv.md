# Arrivals CSV

**Pointer only. No passwords. Starter / guess until they teach.**

The arrivals CSV is today’s expected check-ins: confirmation, guest label, room type, rate code as stored, dates, source, and status. Typical US inns export it each morning. You do not fill blank rates. Group and OTA source stay labels. Checks often want confirmation and room_type columns. This tool feeds arrivals-day, no-show, and group-pickup packs. Early-check-in comments, group codes, and DNR-match flags you add must be labeled as flags, not as PMS truth. Blank rate cells stay blank. This is the usual first file on an arrivals-day pack.

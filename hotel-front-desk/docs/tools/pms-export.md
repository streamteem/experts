# PMS export

**Pointer only. No passwords. Starter / guess until they teach.**

The property-management export is their arrivals, in-house, house-count, or reservation CSV or PDF from Opera, Cloudbeds, RoomKey, innRoad, or a photographed rack. You list from that file. You do not invent a rate, a tax, or a room. No PMS password is stored here. Checks look for the work file they named. This tool starts most day lists and house-count packs. Typical columns include room, type, status, arrival, departure, and rate code as stored. You export nothing yourself; they drop the file. House-count and arrivals workflows both start here when the shop uses one combined dump.

# Rate grid

**Pointer only. No passwords. Starter / guess until they teach.**

The rate grid is their dated dollars by rate code and room type. You quote only what is on it. You do not invent BAR or a fee. Reservation versus grid mismatches are asks. No OTA extranet login belongs here. This tool supports packs that must show a rate was on file, never a guessed price. Date, room type, and rate code are the lookup keys. Closed and min-stay marks stay as loaded. Walk-in quotes and extension nights use this same file. You never fill a missing cell with a remembered BAR.

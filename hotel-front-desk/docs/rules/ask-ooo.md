# Ask when OOO is unclear

**Starter / guess until they teach.**

If out-of-order reason or return date is blank, ask. Do not invent a return. Do not treat OOO as sellable vacant. If arrivals still sell a type that OOO has exhausted, flag the clash. Out-of-service versus OOO follows their legend; missing legend is an ask, not a guess. Pest, flood, and renovation holds are still OOO if they coded them that way. Do not sell an OOO room on the arrivals pack. Estimated return that slipped stays a new ask, not a silent extension you write as fact.

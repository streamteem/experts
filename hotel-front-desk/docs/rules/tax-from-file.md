# Tax only from their tax file

**Starter / guess until they teach.**

Tax names and percents come from their tax file and the folio as posted. Never invent a sales, occupancy, or surcharge percent. Never invent a tax-inclusive total. Folio versus file mismatches are exceptions, not silent recalculation. Exemption is a cert process, not a vibe. State tax pages do not override the folder file. Package splits and outlet posts use the same tax file as room. A guest who “never pays tax at home” is not a reason to zero a line. Ask when the file and the folio disagree rather than averaging them.

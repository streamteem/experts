# Rates only from their file

**Starter / guess until they teach.**

Nightly rates, BAR, packages, and add-on dollars come from their rate grid, reservation as stored, or posted fee file. Missing or blank: ask. Never invent a rate, a weekend bump, or a “market” number. If the reservation and the grid disagree, quote both. Last Saturday’s rate is not next Saturday’s. OTA net is not yours to guess. This is the core of the desk. Walk-in quotes use the same grid as reservations. A manager override exists only if their file names who may override and you still do not type a new dollar. Package and pet add-ons are rates too — still from file.

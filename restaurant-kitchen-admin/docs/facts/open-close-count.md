# Open vs close count

**Starter / guess until they teach.**

Some kitchens count at close so AM prep can start from a file; some count at open; some count both and compare. Use the timestamp and shift they wrote. Do not average two counts to hide a miss. Ask which count feeds the order and which feeds prep. A close count that omits the line is still a partial if they also use station pars. Overnight theft stories are not yours to write; a gap between close and open is a question if both files exist. Do not invent a count because the order cutoff is in an hour. These notes are typical independent timing choices. Their clock and sheet header win. Starter talk is not this shop's close ritual until they teach. Do not invent a midnight count because the morning orderer is late. If they count both open and close, keep both files and do not blend them. Ask which timestamp feeds prep versus the truck.

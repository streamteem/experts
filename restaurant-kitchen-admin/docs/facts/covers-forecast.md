# Covers and forecast

**Starter / guess until they teach.**

Some kitchens set prep and protein pulls from a cover forecast, reservation export, or manager projection instead of a static par. Use that file if they named it, and say the pack is forecast-based. Do not invent covers from the weather, a holiday you remember, or a downtown event you assume. Do not change standing pars because you think Saturday will be busy; flag a question if the forecast and the par file disagree. Reservation no-shows and walk-in assumptions are their numbers. Banquet guarantees, if they have them, stay on the catering pull, not silently mixed into daily station pars unless they merge those files. Missing forecast when they said they prep to covers: ask. Theoretical sales from last year are not this week's forecast unless they filed that sheet. These notes are typical when independents run a projection. Their file wins.

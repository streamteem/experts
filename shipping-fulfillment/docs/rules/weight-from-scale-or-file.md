# Weight from the scale or their file

**Starter / guess until they teach.**

Use only the scale export, a written scale ticket, or a WMS weigh field they stored. Never invent a pound or kilogram to finish a BOL, label, claim, or rate shop. Item-master catalog weight is not scale weight unless their written rule says it is the fallback. If weight is missing on freight, ask. Billed weight on a carrier invoice is copied as billed, not treated as the dock scale. This is the core of the desk.

# Hazmat fields only from their file

**Starter / guess until they teach.**

Proper shipping name, UN number, hazard class, and packing group appear only as their hazmat file already stores them. If a SKU looks restricted and the file is silent, stop and ask. Do not decide the material is not hazmat. Do not copy extra SDS medical notes into docs/. PHMSA pages are orientation. Parcel carrier hazmat help pages are orientation too. You do not browse a public UN list to fill a blank. Stop and ask. Their restricted list is the only source on this desk.

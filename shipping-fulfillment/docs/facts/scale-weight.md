# Scale weight

**Starter / guess until they teach.**

Scale weight is the number from their scale export, floor-scale ticket, or WMS weigh-at-pack field. Typical US SMB ship desks use a bench scale for parcels and a pallet scale for LTL. You copy that number and the unit as labeled. You never invent a weight to finish a BOL, a label, or a claim. A catalog “unit weight” on the item master is not a scale weight unless they said to use it as a fallback and the file shows that rule. If two weigh events disagree, list both timestamps. Missing weight on a freight shipment is an ask, not a guessed hundredweight. Billed weight on a carrier invoice is a different field — see billed-weight-from-invoice-file.

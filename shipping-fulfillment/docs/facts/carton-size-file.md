# Carton size file

**Starter / guess until they teach.**

The carton-size file is their box catalog: name or code, length, width, height, and sometimes a tare. Typical US SMB ship desks pick from a short list of mailers and cartons. You use those inches for DIM questions. You do not invent a new size to make DIM look cheaper. You do not treat a carrier’s public box as their catalog unless it is on their sheet. If pack used a size not on the catalog, list the exception. Missing catalog: ask before any DIM exception pack. Starter until they teach *this* shop’s box codes. This Expert matches pack rows to the catalog. They grab the box. Scale weight is still the scale, not the catalog tare, unless their file says to net out tare and shows how. A mailer versus a carton is a catalog row, not a guess. International size limits on a carrier page are orientation; eligibility still comes from their export. Starter until they teach *this* shop’s box codes. They grab the box on the bench.

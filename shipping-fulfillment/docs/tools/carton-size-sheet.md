# Carton size sheet

**Pointer only. No passwords. Starter / guess until they teach.**

The carton-size sheet is their box catalog: code, length, width, height. You use it for DIM exception packs and pack-rule checks. You do not invent a size. Pack rows with unknown codes are exceptions. This tool pairs with the scale export for dim-versus-scale workflows. Carrier public box lists are not their catalog unless listed. Tare appears only if they stored it. Codes, inches, and optional tare stay as rows. Unknown pack codes are exceptions, not new catalog lines you add. Pair with scale-export for DIM packs. Ask if the sheet is missing.

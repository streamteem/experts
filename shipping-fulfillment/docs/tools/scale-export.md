# Scale export

**Pointer only. No passwords. Starter / guess until they teach.**

The scale export or weigh-at-pack dump is dock truth for pounds: carton or pallet id, weight, timestamp if present. You copy those numbers. You never invent a weight. Catalog item weight is not this file. This tool feeds DIM-versus-scale exception packs and BOL weight lines. Checks look for a weight column when the workflow says so. Missing export: ask, do not guess hundredweight. Pallet-scale and bench-scale rows stay labeled if their export has a scale-id. Mixed units stay as labeled; you do not convert. This is outbound weigh, not a receiving catch-weight sheet.

# Address / validation file

**Pointer only. No passwords. Starter / guess until they teach.**

The address file is the order ship-to export and, if they use one, the validation-result CSV (pass, fail, suggested). You copy ship-to from the live order columns. You do not invent a corrected street. Failed rows feed hold and exception packs. This tool supports hold-and-will-call and any pack that must show destination. No locker or gate code belongs in docs/. International format still is not a customs opinion. Bill-to columns are not ship-to unless they said to use them. Validation fail rows feed holds. International address lines still are not a customs classification. They fix the order in their system.

# Hazmat / restricted-SKU file

**Pointer only. No passwords. Starter / guess until they teach.**

Their hazmat or restricted-SKU file lists which items need special papers and the UN or class fields they already stored. You flag presence and copy stored fields. You do not certify. You do not invent a UN number. Empty file plus a chemical-looking SKU is a stop-and-ask. This tool is a completeness check, not a PHMSA stamp. SDS pointers stay pointers; do not dump extra medical text into docs/. Restricted flags without UN fields still mean stop-and-ask, not ordinary goods. You do not complete a shipping-paper certification from this sheet. Their trained person uses the live hazmat process.

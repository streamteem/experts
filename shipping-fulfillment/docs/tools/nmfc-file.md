# NMFC / class table

**Pointer only. No passwords. Starter / guess until they teach.**

Their NMFC or freight-class table maps SKU or commodity to class and item as they maintain it. You copy class from this file onto a BOL pack. You never invent a class. If the SKU is missing, the pack asks. NMFTA public pages are not a substitute table. This tool supports BOL packs only as a lookup they already own. Reclass disputes still do not become a class you mint. Ask when the SKU is missing.

# Exceptions from their file

**Starter / guess until they teach.**

Late, fail, refusal, detention, and breakdown need a timestamp or a saved note in their exception log, TMS, or driver file. Do not create exceptions from memory of a call, from traffic you cannot see, or from a customer complaint that is not in the folder. If two sources disagree, list both. Use their codes; do not invent a new code. Breakdown still ranks first. Starter / guess until they teach this shop.

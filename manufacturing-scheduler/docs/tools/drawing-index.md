# Drawing index

**Pointer only. No passwords. Starter / guess until they teach.**

The drawing index lists item, drawing number, revision, and file date or path for PDFs they stored. Traveler and job revs are compared here. You do not treat the newest file as released. You do not approve an ECO. Missing prints stay missing. This tool feeds traveler-completeness and ECO-pending packs. No PDM password belongs in the folder. File date and rev both print on mismatch packs. You do not treat the newest PDF as the released print. They release drawings.

# Inventory export

**Pointer only. No passwords. Starter / guess until they teach.**

The inventory export is on-hand, allocated, and sometimes on-order by item, location, and lot if they use lots. You do not invent on-hand. Shortages compare need to this file as of the export date, which you quote. No WMS password belongs here. This tool feeds shortage and kit packs. If the file is stale, say so. Location conflicts stay listed rather than netted into a fake available. Allocated versus on-hand stay separate columns if they exported both. You do not net them into a fake available to hide a short.

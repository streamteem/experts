# Shop calendar file

**Pointer only. No passwords. Starter / guess until they teach.**

The shop calendar lists working days, holidays, shutdowns, and sometimes hours by work center. Capacity packs use this file. You do not invent a Saturday crew. You do not assume five eights if the file is missing — ask. Overtime notes they stored may sit beside the calendar; you still do not approve overtime. This tool feeds dispatch and due-date feasibility flags. Shutdown weeks and inventory-count freezes stay as written. You do not invent a Saturday crew to make finite load fit.

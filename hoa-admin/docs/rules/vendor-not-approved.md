# Do not add an unapproved vendor

**Starter / guess until they teach.**

If they have an approved-vendor or insured-vendor list, do not treat a random PDF, a web search, or an owner’s cousin as awarded or on-call work. Emergency flags still use their after-hours sheet. Missing insurance on a listed vendor is a staff flag, not an award you make. A bid from an unlisted vendor is a question for the board, not a line you add to the approved list. Do not add a vendor to the approved list because a bid arrived; that list changes only when they say it did.

# Do not invent a fine

**Starter / guess until they teach.**

Fine schedule file, resolution exhibit, or software code table—or ask. Do not create a daily fine, escalate a first offense, or copy another community’s amounts to pressure an owner. Waivers are a logged board action, not a courtesy you grant. Late fees on assessments are not covenant fines unless their ledger already combines them. You do not mail the fine letter as counsel. If the schedule PDF and the software code disagree, ask which one staff must use; do not average the two amounts.

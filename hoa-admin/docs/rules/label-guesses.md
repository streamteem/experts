# Label starter guesses

**Starter / guess until they teach.**

Notice intervals, fine amounts, quorum fractions, assessment rates, and statutory day counts not in their files are guesses. Say so, or ask. Do not present starter handbook language as how this association already works. Teach the folder before you write as this community. A neighboring HOA’s schedule is not this board’s adopted number. If you must sketch a typical path to teach the folder, mark every number that is not in their file as a starter guess, and do not treat a CAI article as this board’s adopted rule.

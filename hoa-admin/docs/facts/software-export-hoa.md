# Management software export

**Starter / guess until they teach.**

They export ledgers, violations, work orders, and rosters from management software such as AppFolio, Buildium, CINC, VMS, or from a spreadsheet they already maintain. No login, password, or API key is stored in this folder. Confirm community name, as-of date, and period on the file before you list numbers. Column names vary by vendor; map to the columns they asked for without renaming their lot key. A truncated export, a filter that dropped prepaid lots, or a file that still says the prior community’s name in the header is a question. You do not log into the live site as the manager. One export per working file unless they asked you to append a clearly dated second pull. A second pull the same week gets a new dated filename so two as-of stamps do not collide; do not overwrite last month’s export, and do not keep a screenshot login in the folder.

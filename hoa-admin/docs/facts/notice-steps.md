# Notice steps as their policy file

**Starter / guess until they teach.**

Many US associations use a stepped path such as courtesy or warning, then a formal violation notice, then a hearing, then a fine—sometimes with a cure period between steps. Those steps live in a board-adopted enforcement resolution or rules file, not in this starter. List which step the log says this lot is on and the dates they recorded. You do not skip a step to get to a fine, do not mail the letter as the association’s lawyer, and do not invent a statutory waiting period because another state uses one. If the log says “notice 2” but the policy PDF only has one formal notice, ask which file is current. Returned mail and email-bounce flags are admin facts if they store them; they are not a legal finding that notice was perfected. Courtesy language stays courtesy. One lot and one open track per row unless they asked for a portfolio list.

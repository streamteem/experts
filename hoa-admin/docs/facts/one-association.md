# One association label on every file

**Starter / guess until they teach.**

Management desks often run several communities in one office and reuse street names across towns. Every CSV, write-up, bid table, and meeting list names the association the way their books name it—legal name, DBA, or community code they use. Do not mix two HOAs in one aging, violation, work-order, or roster file. Do not reuse last week’s Oak Hills template numbers on Maple Court. If they asked for a portfolio index, each row still carries a community label. Confirm the name on the software export header. A street that sits in two associations, or a master association plus a sub-association, is a question, not a merge. One community label on every working file is the default. Master associations and sub-associations need separate files even when they share a street or a manager; if they asked for both, each row still names which entity the number belongs to.

# Lot or unit identifier

**Starter / guess until they teach.**

Every violation, work order, dues row, architectural application, and amenity reservation on a typical US community-association desk needs the lot, unit, or address label this association already uses in its books. Planned-unit developments and single-family HOAs often key on a street address or a plat lot number. Condominiums and townhome associations more often use a unit number plus building, and some ledgers still carry a county parcel or tax-map identifier next to the mailbox number. Management companies that run several communities keep the association name and the lot key on the same row so two Oak Streets never collide. Do not invent a lot number from a plat map, a GIS screenshot, or a neighbor’s description. If two labels exist (legal lot versus mailbox, or developer phase versus current street number), ask which one the live log, ledger, and violation software use, and write that one everywhere in this pack. One association per list unless they asked to combine files and every filename already names the community. A missing or colliding lot is a question, not a guess you resolve from a photo.

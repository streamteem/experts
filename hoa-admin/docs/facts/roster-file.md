# Owner roster file

**Starter / guess until they teach.**

A typical US owner roster export includes lot or unit, owner name as they store it, mailing address, and email or phone if they use those for notices. Some books add a second owner, a tenant occupant, a vote-weight column, or an opt-out flag. Completeness of the roster is admin: blank lots, duplicate lots, and addresses that bounce are questions. You do not decide who is the legal owner from a deed, title print, or probate story you interpret. Do not publish the full roster in a write-up that sits where extra contact data is not needed; use lot and name when that is enough. Management desks that run several communities must keep the association name on every row. Do not merge two communities because the street names match. One association per roster file unless they asked for a labeled multi-community index.

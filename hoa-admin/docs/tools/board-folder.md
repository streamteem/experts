# Board meeting file folder

**Pointer only. No passwords. Starter / guess until they teach.**

The folder or packet drop for the next meeting they name: agenda draft, prior approved minutes, financial exhibits they already produced, and other PDFs they listed. List what is present or missing so the checks can see a file-and-present table. They run the meeting. Do not add motions or invent attendance. Keep owner aging out of any file that will be posted unless their template already separates it. One meeting date and one association per index.

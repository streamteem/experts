# Violation or site photo folder

**Pointer only. No passwords. Starter / guess until they teach.**

Named site or violation image files tied to a log row, exported from software or dropped by staff. If the file is missing, will not open, or is a broken portal link, ask. Do not invent what an unopened photo shows. Describe only obvious admin facts they asked for when the file opens. Do not close the item as resolved without the required image. Extra plates stay off the write-up unless their log uses them.

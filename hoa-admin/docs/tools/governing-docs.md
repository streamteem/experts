# Governing documents folder

**Pointer only. No passwords. Starter / guess until they teach.**

Declaration, CC&Rs, bylaws, articles, and adopted rules they keep as PDFs. Quote only pages they point to, with document name and section as written. Do not interpret as counsel or declare a clause unenforceable. Drafts and email redlines are not official until they say so. If two dated versions disagree, ask which file is current. Confirm the association name on the cover page. Amendments and restatements belong on the same index with dates; do not quote an old scan when they named a later file.

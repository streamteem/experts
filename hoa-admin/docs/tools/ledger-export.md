# Dues ledger export

**Pointer only. No passwords. Starter / guess until they teach.**

Management-software or accounting export of assessments and other charges: lot, balances, and aging buckets as coded. Period, as-of date, and community name must be on the file. No login, password, or API key here. Do not threaten collections from this file. Prepaid lots are not delinquencies. Late-fee columns stay as exported. One association per export unless they asked for a labeled combined pull. If two exports disagree on a lot balance, keep both dates visible and ask which pull they want on the write-up.

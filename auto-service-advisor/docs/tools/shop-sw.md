# Shop software export

**Pointer only. No passwords. Starter / guess until they teach.**

Pointer to how they export the RO list or a single RO as CSV, PDF, or screenshot from the shop system they actually run. Typical columns are RO number, vehicle, concern, status, promised time, pay type, and auth flag. Independent shops may use Tekmetric, Shop-Ware, Mitchell, or similar; dealers often use a DMS. No login. Ask which product they run and which export they trust. Use the file to build open-RO rows and one-RO identity, not to invent status. Do not treat the export as a diagnosis or a safety stamp. If columns are missing, ask. This is a pointer, not a claim they use a named brand.

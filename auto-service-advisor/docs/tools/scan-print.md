# Scan tool or battery printout

**Pointer only. No passwords. Starter / guess until they teach.**

PDFs or photos of scan results, battery tests, or calibrations they attached. Quote codes, freeze-frame, and readings as printed. Do not add codes. A code is not a complete cause. Independent and dealer scan attachments are the only source. If the file is unreadable, ask. Do not treat a battery print as a safe-to-drive stamp. History versus current labels stay. Use these files to support cause only as the tech already used them. Pointer to their printouts, not a tool you operate in the bay.

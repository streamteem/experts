# No invented codes

**Starter / guess until they teach.**

Codes come from their scan printout or tech note. Check engine is a concern, not a code. Do not invent P-codes, pending codes, or freeze-frame. Do not treat a code as a complete cause or as a parts list. Independent and dealer attachments are the only source. If the printout is missing, ask. History versus current labels stay as printed. A code does not decide OEM versus aftermarket. You do not add codes from memory of that model year.

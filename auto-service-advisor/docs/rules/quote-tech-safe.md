# Quote the shop if they used 'safe'

**Starter / guess until they teach.**

If a manager or technician note says they released the car, quote that note. You do not add safety language. Ready, QC passed, and released are their words in quotation marks. Independent and dealer customers hear safe to drive; this pack does not supply it. MPI green is not that sentence. OEM parts are not that sentence. If the file has no release note, say the file has none. Do not soften or strengthen their wording.

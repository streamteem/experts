# MPI only from their form

**Starter / guess until they teach.**

List red, yellow, green, or their equivalent only from the form they use. Do not import a generic 50-point checklist. MPI is not a state inspection and not a pass sticker. Photos only if attached. A caption is not a diagnosis unless the tech wrote one. Independent DVI and dealer factory MPI both count; empty boxes stay empty. Recommendations still need their prices and new auth. Do not upgrade a yellow to red. If the export is missing, ask rather than filling from memory of the car.

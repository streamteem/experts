# Fleet PO if their process requires it

**Starter / guess until they teach.**

If their fleet process needs a purchase order and the field is empty, list it as blocking. Do not invent a PO, unit number, or national-account rate. Driver permission is not a PO unless their file says so. Independent local fleets and dealer national accounts both have open rules; use theirs. Auth limits on the PO still apply to additional findings. You do not start sold work in the pack without that field when they require it. Ask which bill-to is live if two appear.

# Correction from tech file

**Starter / guess until they teach.**

Do not write a correction that is not on the closed RO or tech notes. Replaced pads without their line is invention. Do not expand a billed operation into extra work the file does not show. Software updates, fluids, and sublet count only as they recorded. Independent menu names and dealer factory operations should be copied, not improved. A missing correction on a closed paid job is a question. Correction is not a safe-to-drive stamp. Leave it blank when the job is still open.

# Codes from their scan

**Starter / guess until they teach.**

Diagnostic trouble codes come from their scan tool printout or the technician's note. Copy the code and the freeze-frame they saved. A code is not a complete cause. Do not invent P-codes from a check engine concern. Independent and dealer bays both attach screenshots or printed reports; use those files only. Pending, current, and history codes are different if their printout separates them; keep the labels. Do not treat a code as proof a part must be replaced, and do not treat the absence of a code as proof the car is safe. OEM versus aftermarket parts are a quoting question, not a ruling from a code. If the printout is unreadable, ask for another save. Codes exist so cause can be written after tests, not instead of tests. Typical practice until they teach which scan files this shop attaches to the RO.

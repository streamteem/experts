# Core charges

**Starter / guess until they teach.**

Remanufactured and some exchange parts often carry a core charge that is credited when the old unit is returned in the condition the vendor requires. List the core only if their invoice, parts sheet, or RO settings show it. Do not invent a core amount from another shop. If a core is still open on an old RO, flag it as a question for the parts person. Independent jobbers and dealer depots both use cores; the paperwork name may be core, exchange, or deposit. Copy their label. Core is not a diagnosis that the old part failed, and it is not a safety opinion. Do not treat an unreturned core as customer-pay extra unless their file already billed it. If the tech has not pulled the old unit, do not mark the core as returned. The desk keeps cores so the invoice and vendor credit can match later. Starter until they teach how this shop tracks open cores.

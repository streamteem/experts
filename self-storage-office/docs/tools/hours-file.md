# Hours and holiday file

**Pointer only. No passwords. Starter / guess until they teach.**

The hours file is office-open hours, gate-access windows as process (not codes), and holiday closures they stored. You copy both office and gate if they split them. You do not invent a Sunday opening. After-hours emergency process notes are fine; keypad secrets are not. Move-in and waitlist tours should respect office hours unless the file says otherwise. No gate-system password belongs here. Checks look for the hours file when a pack needs it. This tool orients after-hours and scheduling notes on other packs.

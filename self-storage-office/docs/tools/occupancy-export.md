# Occupancy or rent-roll export

**Pointer only. No passwords. Starter / guess until they teach.**

The occupancy export is dock truth for who is in which unit: unit, status, occupant label, and often rate and paid-through. You do not mark occupied from a lock photo. Reserved, company, damaged, and auction-hold stay as coded. The Expert may run Python to chart occupancy by size or building from this file if they asked; correlation is not causation. No PMS password belongs here. Checks look for unit and status when the workflow asks. This tool feeds occupancy and transfer-list packs and vacancy-day lists.

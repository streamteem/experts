# Unit-mix CSV

**Pointer only. No passwords. Starter / guess until they teach.**

The unit-mix CSV is their export or workbook of unit number, size label, climate or standard, and sometimes building. Typical US offices export from SiteLink, storEDGE, SSM, or a numbered sheet. You list mix and flag blank sizes. You do not invent a ten-by-ten count. The Expert may run Python in this workspace (pandas, matplotlib) to write a mix summary CSV or a bar chart in out/ if they named the question and columns; if a package is missing, say so and do not pretend a chart exists. No software login is stored here. Checks look for unit and size when the workflow asks. This tool feeds unit-mix packs.

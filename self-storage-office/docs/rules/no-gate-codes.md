# Never store gate codes

**Starter / guess until they teach.**

Never write a gate code, keypad PIN, master code, fob secret, or temporary contractor code into this folder, docs, work, or a write-up. Describe process only: who issues, when access is on or off, hours. If a PDF or CSV contains codes, stop and ask for a redacted file; do not copy that column forward. Status active or inactive is fine. Overlock combinations are also secrets. They keep codes in their vault or management system. This rule does not yield for convenience.

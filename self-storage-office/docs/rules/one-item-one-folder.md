# One work item, one folder

**Starter / guess until they teach.**

Do not pile every day’s files into one shared `work/` or `out/` folder. Open or create one folder under `items/` for this appointment, ticket, period, or pack **before** producing files. If it is unclear which item this is, ask. Do not add a second patient, ticket, or period to an open folder unless they asked for a combined pack and named it. Prefer their id (chart, RO, PO, unit) in the folder name. Finished work stays in that folder’s `out/`.

# Ingest example

## When

“This is how we did it last time.” File or paste attached.

## Do

1. Read the example. List possible facts, rules, tool notes, workflow steps.
2. Show the list. Ask which to keep (do not save mistakes from a bad sample).
3. **remember** / workflow stubs for what they approve.
4. Journal: saved from `<filename>`.

Do not copy the whole example into one blob. Split it into facts, rules, tools, and steps like everything else.

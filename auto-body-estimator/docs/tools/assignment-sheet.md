# Assignment sheet

**Pointer only. No passwords. Starter / guess until they teach.**

The assignment sheet is their insurer assignment PDF, DRP export, or intake workbook: claim, VIN, DOL, insurer, deductible if shown. You copy fields. You do not invent an assignment. Customer-pay rows may have no claim number. No portal password belongs here. This tool starts assignment-intake and supports authorization-missing. Checks look for claim and vin when asked. DOL, insurer, and deductible if shown stay copied. A walk-in sheet with no claim number is still a file if they use it for customer-pay. Distinct from a mechanical RO open.

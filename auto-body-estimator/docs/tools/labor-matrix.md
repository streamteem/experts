# Labor matrix / rate file

**Pointer only. No passwords. Starter / guess until they teach.**

The labor matrix is their rate sheet or estimating-system labor export: labor types, hours, and dollars they already set. Typical US collision shops live in CCC, Mitchell, or Audatex plus a DRP rate letter. You copy hours; you never invent them. No estimating-system password belongs here. This tool starts estimate-from-files. Checks look for op and hours when the workflow asks. Missing matrix: ask. Structural and ADAS rows on this file are still not stamps. If the letter and the system rates disagree, the pack lists both. Starter until they teach which matrix applies to which carrier.

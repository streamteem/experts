# Paint code

**Starter / guess until they teach.**

The paint code is the factory or shop color identifier they recorded from the label, the VIN decode they ran, or the paint-counter formula they filed, not a color you guess from a photo. Typical US collision shops write the code on the estimate refinish header and keep a formula print or mix sticker. Copy the code. Do not invent a paint code from a remembered model color name. Do not promise a match. If the label photo and the estimate code disagree, list both. Two-tone or roof codes stay as they wrote them. Materials dollars still come from their file, not a guessed mix weight. A mechanical “touch-up paint” SKU on an RO is not this code unless they attached it. This Expert copies codes and flags fights. They mix. Starter until they teach where *this* shop reads the code on each make.

# Shared inbox as an export

**Starter / guess until they teach.**

If they export a shared inbox or a help mailbox to CSV for a pack, you read the export. You do not send, reply, or run email as a product. Draft text lives in a file they may paste. Typical export columns are date, from, subject, and a status they already use if present. Do not scrape a live mailbox with a password. You do not run a CRM, drip, or marketing blast from the export. PII in a message body is not copied into docs/ beyond what the pack needs; prefer ticket IDs they already use. Starter notes describe common SMB shared inboxes; they still teach whether this shop even exports. After-hours or reception scripts stay on their one-pager, not as an auto-reply you turn on. Confidential legal mail they marked stays unopened. This is not customer notification for an incident.

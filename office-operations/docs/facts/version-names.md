# File names and versions

**Starter / guess until they teach.**

Offices lose work when final2-really-final proliferates and nobody knows which PDF was signed. Use their naming rule if they taught one: date prefix, project code, or a version cell on a tracker. Until then, keep the name they used and note the date modified from the file system or folder they showed. Do not silently replace a signed PDF, a lease scan, or a wet-ink image with a 'cleaner' export. Do not rename legal-looking titles to please a template. If two files share a stem, list both paths and dates and ask which is current. Work/ and out/ names follow the work map for this pack; that is not a license to rename their live Drive originals. 'Latest' in a filename is not proof of signature. Starter notes describe common SMB version messes; they still teach this shop's rule. You do not delete old versions from their drive. Draft agendas may use a dated work/ name while their template in docs/ keeps the name they chose.

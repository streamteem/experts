# Password tools are pointers only

**Starter / guess until they teach.**

NIST small-business cyber notes often include unique passwords and a vault. You never store passwords, bank logins, or card numbers in this folder. If a checklist says 'vault owner,' name the role they wrote, not a secret. Typical pointer fields are system name and owner role. You do not reset a password, join their vault, or 'help' by typing a credential into work/. Shared mailbox and postage-meter logins follow the same rule. Starter notes describe how many SMB offices point at a vault; they still teach who owns it here. A failed backup or a locked vendor portal is a flag, not a reason to store the password. This is not an IT admin product. Do not paste a temporary code from an SMS they showed you. Alarm codes stay off the key log and off this pointer file. A vendor portal login hint they wrote as a role name is enough; never the secret itself.

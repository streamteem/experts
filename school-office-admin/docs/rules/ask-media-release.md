# Ask or exclude when media release is missing

**Starter / guess until they teach.**

Do not put a student on a yearbook, newsletter, or photo list if the media-release is missing or marked no. Do not assume directory permission covers photos if they use two forms. Ask when the form is blank. They publish. You filter the list. Blank, missing, or no means the student stays off photo and yearbook drafts. Directory opt-out is a second filter if they use two forms. Do not assume last year's yes. They publish. You filter.

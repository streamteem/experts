# Attendance CSV

**Pointer only. No passwords. Starter / guess until they teach.**

The attendance CSV is the dated mark file: student, date, and their code for present, absent, tardy, or excused. Typical offices export a day or a week. You do not recode. You do not invent an excuse. Checks look for student and date columns when the workflow asks. This tool is the source for the attendance-day pack. Closed and late-start days stay labeled if the file has them. Period marks and daily marks are different files if they split them — do not merge silently. Blank codes stay blank. This tool does not recode excuses. Date must match the day they asked for.

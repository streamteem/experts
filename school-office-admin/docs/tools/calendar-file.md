# Calendar file

**Pointer only. No passwords. Starter / guess until they teach.**

The year calendar PDF or CSV lists instructional days, holidays, early-outs, and exam windows. You copy dates. You do not invent a snow makeup. Bell-schedule versions that attach to dates belong with this file when they stored them. This tool is the source for the calendar pack. If two calendars disagree, the pack quotes both. Early-out and late-start rows should carry a schedule-version label if they use one. Board-revised dates replace the spring PDF only when they dropped the revision. Feeds the calendar-pack workflow.

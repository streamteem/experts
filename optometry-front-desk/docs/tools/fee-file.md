# Fee and posted-copay file

**Pointer only. No passwords. Starter / guess until they teach.**

Their private-pay and posted-copay files for exams, frames, lenses, treatments, adjustments, and repairs. Amounts and estimate lines, when they ask, start here plus their estimate screen or eligibility print. No guessed fees from another optical or a public average. Ask which schedule a row uses if more than one exists. A fee is not an allowed amount and not a promise of payment. You do not pick a lens type to match a dollar. If the file date looks old, ask. Point at the file; do not paste the whole schedule into every write-up. Starter / guess until they teach which fee file is live.

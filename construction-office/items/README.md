# Work items — keep days and appointments apart

Each **work item** gets its own folder here so work does not pile into one shared `work/` or `out/` pile.

What counts as one item depends on this desk (appointment, ticket, repair order, books period, property + unit). Read `docs/facts/how-we-file.md`. Until they **teach**, use that starter pattern.

## One item folder looks like this

```
items/2026-09-15-1000-chart-4412/
  in/         files they dropped for this item only
  work/       scratch for this item
  out/        finished list or write-up for this item
  evidence/   check logs for this item
```

## How to use it

1. Say which item this is (the 10 a.m. appointment, ticket 441, August operating bank).
2. The Expert creates or opens **one** folder and puts today’s files there.
3. Tomorrow is a **new** folder. Do not drop new files into yesterday’s folder.
4. Look in that folder’s `out/` for the finished pack. The list of items is `items/INDEX.md`.

If they already have a filing system (their software’s number, a property code), use **their** names.

The top-level `work/` and `out/` folders are leftovers. **Do not put new day-to-day work there.**

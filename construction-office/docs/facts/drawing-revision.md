# Drawing revision set

**Starter / guess until they teach.**

Offices keep a current set and a record of superseding sheets so the field is not building from an old bulletin. Use the revision letter, cloud number, or issued date in the filename or title block they gave you. Do not call a folder the stamped set unless the file name or their note says so. Mixed revisions in one pack: list each sheet's revision and ask which is current. Issued-for-construction, addendum, bulletin, and as-built are different labels; keep theirs. Do not flatten an IFC set and a later bulletin into one current set name. Some remodelers work from a single marked-up PDF; some GCs keep a drawing log with sheet number, title, and revision. Use their log if they have one. You do not decide which cloud is in scope. If two files share a sheet number and different revisions, quote both and ask. Never invent a revision letter to fill a blank title block.

# Revision from the filename or title block they gave

**Starter / guess until they teach.**

Do not declare a set current from memory, a hallway comment, or last week's folder name. Quote the revision letter, cloud, or issued date on the file they gave you. If IFC and a later bulletin both appear, list both and ask which is current. Do not flatten mixed revisions into one current-set label. Title-block dates and filename dates can disagree; quote both. You do not decide which cloud is in scope. Never invent a revision letter to fill a blank. Their drawing log, if they have one, is the index source.

# Do not silently mix drawing sets

**Starter / guess until they teach.**

If issued-for-construction sheets and a later bulletin both appear, list both. Do not flatten them into one current set label or pick a winner from memory. Quote revision letters from the title block or filename they gave you. Mixed revisions in a single PDF still get listed sheet by sheet when they asked for that. As-built markups are not the IFC set. You do not decide which cloud is in scope. Ask which set the field should treat as current. Their drawing log, if present, is the index, not a set you rebuild.

# Quote the file

**Starter / guess until they teach.**

Status words such as approved, rejected, rain day, passed, and complete must come from a named file. If it is not there, say missing. Do not upgrade a hallway comment, a photo caption you wrote, or a look-ahead line into a status. When two files disagree, quote both and ask which is current. Amounts, dates, headcounts, and certificate expirations are copied as printed. Your write-up should name the source path they pointed to. Starter language is not a source. If they did not give a file, the pack stays a question list.

# Drawings folder

**Pointer only. No passwords. Starter / guess until they teach.**

Current and superseded PDFs they point to, plus any drawing log they already keep. Index revision from the filename or title block they provided. Do not claim a stamped set unless the file says so. Mixed IFC and bulletin sheets stay listed separately. You do not flatten revisions or add clouds. As-built markups in the same folder are still markups, not sealed record drawings. Not-for-construction labels stay on the pack. This is a folder pointer, not a CAD license. When two files share a sheet number, quote both revisions and ask which is current for the closeout or daily pack that pointed here.

# Pay application folder

**Pointer only. No passwords. Starter / guess until they teach.**

Monthly PDF or export plus waivers if they file them there. You list application number, period, and missing pages. You do not certify payment, lien rights, or stored-material title. Continuation-sheet gaps are named as absent pages. Retainage is copied, not released. AIA-style form numbers appear on some jobs; others use a plain invoice. Use their names. Never send the application or move funds. Stored-material backup is listed if present. This folder is a pointer, not an accounting login. The pack quotes printed totals; it does not fix the math unless they asked you only to note a mismatch.

# Closing file index

**Pointer only. No passwords. Starter / guess until they teach.**

The closing file index lists settlement statements, Closing Disclosures, deeds they were sent, funding and recording confirmations, and keys or possession notes as files present. Typical US residential desks keep this as a CSV next to the title folder. You do not mark funded without their confirmation. You do not attach wire instructions. CD versions are dated rows. This tool feeds the closing-checklist workflow. Cash versus financed labels follow the PDFs they stored, not a guess.

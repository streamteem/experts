# Business-day rules from their file

**Starter / guess until they teach.**

Use the business-day or calendar-day definition on the executed form or the written broker or state-association note they stored. Do not import a CFPB Closing Disclosure definition onto a purchase-contract clock. Do not assume weekends drop out. Holidays move a date only if their file says so and only using their holiday list. Missing definition: ask. Label each deadline with the day-type you actually used and the source page. If two forms on the same deal use different day types, label each row and do not merge the clocks.

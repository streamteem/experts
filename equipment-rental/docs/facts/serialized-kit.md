# Serialized kit

**Starter / guess until they teach.**

A serialized kit is a set of pieces each with a serial or asset tag: radio remotes, hose reels, fork sets, or crib tools. Typical US SMB yards track these because they walk away. Outgoing and return inspections should list each serial their kit file names. You do not invent a kit serial. You do not substitute a remote serial without asking. Lost-item prices still come from their file. Cycle counts should include kit serials when their count process says so. Starter until they teach which kits *this* yard serializes versus quantity-only. Photos of tags help. You do not diagnose a dead remote as a mechanic; you note “no power” if that is what they wrote. Contract lines should carry the kit serials their process requires. Missing kit serial on a high-value remote is a completeness miss before the gate if they require it.

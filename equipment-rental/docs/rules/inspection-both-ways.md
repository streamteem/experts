# Inspect outgoing and return

**Starter / guess until they teach.**

When their process requires it, outgoing and return inspections are both present before you call a damage pack complete. Do not charge from a return note that has no outgoing baseline unless they wrote that exception. Do not skip outgoing to hurry a reservation. Meter, fuel, kit, and photos belong on both sides as their form lists. Incomplete outgoing is a gate question. Incomplete return is a charge-completeness question. They still decide the charge.

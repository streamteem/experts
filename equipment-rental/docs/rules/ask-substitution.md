# Ask before substituting class

**Starter / guess until they teach.**

Do not silently swap boom for scissor, diesel for electric, or a different capacity class. Use their substitution rule. If the file is silent, ask. Price the unit that will actually go, from the rate file. Serial and kit follow the substitute. Same-class serial swaps still need their rule when a named unit was promised. They call the renter unless they asked you only to list options. Indoor-versus-outdoor notes travel with the swap.

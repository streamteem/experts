# PIMS export date stamp

**Starter / guess until they teach.**

Cornerstone, Avimark, ezyVet, Instinct, Pulse, Shepherd, and other practice systems are names you may see on a file header. The tool is the export they give you, not a login. Confirm the timestamp and the site name before you treat a file as today's book, today's reminders, or today's prices. Yesterday's export used as today is a question. No password, API key, or staff PIN is stored here. Column names vary by vendor and by how they built the report; map to the columns they asked for, do not invent fields. Starter / guess until they teach which report, which user runs it, and how often they drop a fresh file in the folder. A report titled 'appointments' without a date in the filename still needs a stamp in the sheet or the export footer. If two files arrive, use the newer stamp after you ask. Do not keep a staff login next to the CSV. Column mapping is theirs to teach when vendor names differ from the starter list.

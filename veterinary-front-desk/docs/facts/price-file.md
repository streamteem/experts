# Clinic price file

**Starter / guess until they teach.**

Estimates and invoice drafts pull item names and amounts from their current clinic price file or fee schedule export. Inventory items, professional services, and in-house lab codes may live on different tabs; keep the tab they named. If a line is not on the file, ask. Do not use a web average, a neighboring hospital's menu, or last year's printout when they handed you a dated current file. Species or weight-banded fees must match stored patient data. Package prices, if they sell wellness plans or bundled dentals, are named rows, not a discount you invent. Confirm the effective date on the export before you treat it as today's fees. You do not change a doctor's fee as a courtesy. Starter / guess until they teach which file is live, who updates it, and whether relief doctors use the same schedule.

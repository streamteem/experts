# Clinic software export

**Pointer only. No passwords. Starter / guess until they teach.**

They export appointments, reminders, invoices, patient lists, or production reports from the practice system they already use. Common US names you may see on a header include Cornerstone, Avimark, ezyVet, Instinct, and others; the product name is a label, not a login. No password, API key, or staff PIN is stored here. Ask which report and the file date before you treat a CSV as today's book. Map to the columns they named. You do not change the live schedule inside the software. Starter / guess until they teach which user runs the export and where they drop it.

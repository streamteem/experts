# No WMS login in the folder

**Starter / guess until they teach.**

Exports, PDFs, and scanner CSVs only. Never store passwords, WMS logins, scanner admin PINs, EDI mailbox secrets, or broker portal credentials in this folder. If they need a new export, they run it. You do not log into their warehouse product as an administrator. A user ID on a count file is fine to copy as who counted; a password is not. Starter notes never ask them to paste a secret. If a secret appears, do not repeat it in a pack.

# Do not invent SKUs

**Starter / guess until they teach.**

Unknown barcode, vendor catalog number, or description: list the raw code and ask. Do not create a catalog number, internal SKU, or synonym to tidy an exception. Do not assume the same description is the same item. Use their item master and vendor-SKU map when those files exist. A missing SKU on a dock line stays an exception. Starter notes are not their catalog. You never present a made-up SKU as if it already lived in this shop.

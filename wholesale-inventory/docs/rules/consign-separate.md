# Consignment stays labeled

**Starter / guess until they teach.**

Do not add vendor-owned, customer-owned, or VMI stock into house on-hand, house available, or house value totals unless they said to. Keep the owner code on every line. Do not reorder consignment as house min-max. Do not write it off as house shrink. Counts should list owner so a physical does not swallow someone else's units. If the owner flag is missing, ask. Their program file wins. You do not pay a consignment draw.

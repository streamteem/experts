# Count or receive scanner export

**Pointer only. No passwords. Starter / guess until they teach.**

If they count or receive with a scanner, that export is the count or the dock quantity. Keep barcode, SKU if translated, quantity, location, user, and timestamp if present. Unknown barcodes stay on an exception list; do not create a SKU. Case versus each barcodes convert only with their master pack. A file that shows system on-hand is not a blind count. You do not store scanner admin PINs. Duplicate serials or plates are flags. Their export, not a retyped memory, is the source.

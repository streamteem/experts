# Do not invent a mow height

**Starter / guess until they teach.**

Deck height comes from their property note or HOA spec. Blank: ask. Do not prescribe inches from a turf-type memory. Do not tell them to scalp or raise as agronomy advice. If spec and note disagree, quote both. Height changes after a complaint are their edit on the ticket, not a silent default you apply to the route. A drought or a complaint is not a new default you apply to the whole route. Ask which property the new height belongs on. Their hole-number or inch note wins.

# Access is an ask; codes stay out of docs

**Starter / guess until they teach.**

Access is whether the crew can get onto the property: gate, lockbox, HOA clicker, dock hours, or a dog that must be inside. Typical US commercial and gated-community routes fail when the office forgets a window or a holiday gate. Ask whether access is solved. Never store a gate code, lockbox combo, alarm PIN, or door code in this folder, in docs/, or in a write-up. If their export already dumped a code into a CSV, do not copy it forward; say access notes exist in their system and they must handle codes there. Time windows and “call ahead” flags are fine to list. After-hours or weekend access is their note. You flag missing access. They keep secrets in their own lockbox. Starter until they teach how *this* shop shares clickers without writing numbers into the Expert folder. A holiday or after-hours window is still not a code. If two properties share a clicker in their note, say shared access exists without writing the secret.

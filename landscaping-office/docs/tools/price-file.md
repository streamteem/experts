# Price file / menu

**Pointer only. No passwords. Starter / guess until they teach.**

The price file is their dated menu or unit-price book: item, unit, and price. Estimates and extra-work drafts copy from here only. Expired or missing book: ask. You do not invent a dump fee, snow rate, or wage. Checks may look for item and price columns. This tool feeds estimate-from-price and enhancement packs. Proposal PDFs should not contradict this file unless they said the PDF is the award. No vendor-portal password belongs here.
